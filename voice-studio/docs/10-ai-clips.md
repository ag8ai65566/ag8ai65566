# 10. 用 AI 先篩直播片段

如果你先用別的 AI 從直播裡挑片段，再匯入 Voice Studio，這一章有兩部分：

- **A. 給篩選 AI 的指示**：整段複製，貼給那個 AI。
- **B. 拿到結果之後**：怎麼匯入 Voice Studio。

Voice Studio 自己會切句、轉文字、認人、打分數和自動審核，所以篩選 AI 的工作是**挑對素材、標好語言和情緒、找出口頭禪和開場招呼**，不需要它切到每一句，也不需要它修音。

為什麼要這樣挑（每一條的理由）：[〈理想的訓練音檔〉](13-ideal-audio)。

---

## A. 給篩選 AI 的指示（從這裡複製到「指示結束」）

### 任務

你要從直播錄影裡，挑出用來訓練「一個人」語音模型的錄音片段。模型要學的是這個人的音色、口音、語調、說話習慣和口頭禪，日文和英文都要。

- 目標說話者：〔填這個人的名字〕
- 這個人已經同意自己的聲音被用來訓練。**只收這個人的聲音。** 聯動的對象、來賓、朋友，除非他們本人也同意，否則他們說話的部分一律不要；他們和目標說話者同時說話的地方也不要。
- 目標總量：交出 **12–14 小時**目標說話者的乾淨語音（之後的檢查會再排除一部分，最後要留下 8–10 小時）。日文、英文**各至少 3 小時**。

### 要收的片段

只收同時符合下面全部條件的段落：

1. 從頭到尾只有目標說話者在說話。
2. 背景沒有音樂、遊戲音效、影片聲音、提示音（斗內、訂閱通知）。有很小聲、一直不變的背景音樂可以收，但要分開放，而且要符合下面「有背景音樂的片段（bgm/）」的全部條件。
3. 聲音清楚：沒有爆音、沒有斷訊、沒有明顯回音、沒有變聲器或特效。
4. 是正常說話：聊天、反應、解說、念留言、念稿都可以。
5. 每個檔案是一段**連續的說話**，長度 10 秒到 10 分鐘。不用切到每一句，Voice Studio 會自己切。
6. 大部分來自這個人平常用的主力麥克風。換過麥克風、在外面用手機錄的、音質明顯不同的，可以少量收，並在 notes 註明。

### 不要收的片段

| 不要 | 原因 |
|---|---|
| 唱歌、哼歌、卡拉 OK | 不是說話，會讓模型亂掉 |
| 別人說話、或和別人同時說話 | 模型會學到別人的聲音；沒有同意的人不能收 |
| 聊天室的機器人朗讀、念斗內的合成語音、遊戲角色語音、播放的影片 | 不是目標說話者 |
| 模仿別人、角色扮演的怪聲、刻意變聲 | 不是這個人的自然聲音（真的想要的話，另外放一個資料夾，情緒標成空白，並在備註寫明） |
| 大笑、尖叫、哭喊為主、幾乎沒有字的段落 | 沒有可以對應的文字 |
| 爆音（大叫時破音）、斷訊、麥克風被碰到 | 瑕疵會被模型學走 |
| 長時間沉默、只有打字聲或遊戲聲 | 沒有說話 |
| 開場、結尾的固定招呼重複很多次 | 同一句（含小變化）最多收 5 次，太多會讓模型念什麼都帶著招呼的語調。招呼本身另外照「口頭禪和開場招呼」交短錄音 |

### 怎麼切

- 起點和終點落在**停頓**上，前後各留 0.3–0.5 秒，不要切到字。
- **不要處理聲音**：不要降噪、不要 AI 人聲加強、不要正規化音量、不要壓縮、不要加淡入淡出。原樣切下來就好，處理過的聲音會改變音色。
- 輸出 **WAV 或 FLAC**，44.1 kHz 或 48 kHz。不要轉成 MP3。
- 同一場直播最多收總量的 10%（例如總共 12 小時，一場最多約 1 小時），盡量分散到不同日期、不同類型的直播（雜談、遊戲、企劃），讓麥克風、心情、場合都有變化。

### 數量和分配

- 平常聊天（平靜、開心）約 50–60%，強烈情緒（興奮、生氣、難過、害怕、悄悄話等）約 20–30%，念稿或念留言約 10–20%。
- 每一種出現過的情緒，至少收 10 分鐘。真的找不到就照實回報，不要用不符合的片段湊。
- 日文和英文分開計算；一句裡日英夾雜的放在「mixed」。
- 內容要多樣：問句、感嘆、長句、短反應、列舉、解說都要有，不要集中在同一個話題或同一款遊戲。
- `bgm/` 最多佔總量的 30%。乾淨的素材夠的話就少收或不收；`bgm/` 主要用來補 `clean/` 裡不夠的情緒、語言或場合。

### 有背景音樂的片段（bgm/）

`clean/` 的標準完全不變。另外，**同時符合下面全部條件**的片段可以放進 `bgm/`，clips.csv 的 bgm 欄標 `low`：

1. **音樂很小聲**：人聲清楚地蓋過音樂，音樂只是隱約聽得到（大約比人聲小 20 dB 以上）。要仔細聽才聽得出旋律的程度才算；一聽就知道在放什麼歌的，不要。
2. **一直不變**：同一首曲子、音量穩定。中途換歌、音樂突然變大、淡入淡出的段落不要。
3. **音樂裡沒有人聲**：有歌詞、合唱、人聲取樣、口白的音樂一律不要（去背景音樂時，歌手的聲音會被當成人聲留下來）。
4. **只有音樂**：同時有遊戲音效、提示音、別人說話的，不要。
5. 其他條件和 `clean/` 一樣：只有目標說話者、沒有爆音、沒有回音、沒有處理過。

拿不準是不是夠小聲、或聽不出音樂裡有沒有人聲的，就不要收。
- 保留說話習慣：「えっと」「あの」「um」「like」、說錯重講、結巴都是這個人的習慣，不要因為這些而排除片段。

### 情緒標籤

每個檔案標一個情緒，只能用下面的代碼（12 種情緒，加上不確定時用的 `none`）。**整個檔案大部分（超過六成）都是同一種情緒才標**；混在一起或不確定，就標 `none`。

| 代碼 | 意思 | 例子 |
|---|---|---|
| `neutral` | 平靜、平常的語氣 | 一般聊天、說明規則 |
| `happy` | 開心、愉快 | 收到禮物、聊到喜歡的東西 |
| `excited` | 興奮、高亢、很有精神 | 遊戲贏了、驚喜 |
| `angry` | 生氣、不耐煩、吐槽很兇 | 遊戲一直輸、被整 |
| `sad` | 難過、低落、感傷 | 說到不捨的事 |
| `soft` | 小聲、溫柔，但還是正常發聲 | 深夜雜談、哄人 |
| `laughing` | 邊笑邊說（字還聽得清楚） | 講好笑的事講到笑出來 |
| `surprised` | 驚訝、嚇一跳 | 突然發生的事 |
| `scared` | 害怕、緊張 | 恐怖遊戲 |
| `whisper` | 氣音、悄悄話 | 刻意的耳語 |
| `teasing` | 撒嬌、調皮、逗人 | 開玩笑、裝可愛 |
| `narration` | 念稿、念留言、旁白 | 念斗內留言、念預先寫好的文字 |
| `none` | 不確定或混在一起 | |

### 口頭禪和開場招呼

找出這個人最有特色的 3–10 個口頭禪。**開場和結尾的固定招呼**（例如「こんばんは〜○○です」「おつ〜」）一定要算進來，其他像反應詞、固定句型也算。每一個：

1. 寫出最常見的**寫法**，以及其他可能的寫法（例如「やっほー」「ヤッホー」「やっほ〜」）。
2. 數一下在你收的片段裡大約出現幾次。少於 20 次的在報告裡標出來。
3. 另外切出 **2–5 段只有這個口頭禪的短錄音**（0.3–5 秒，前後各留 0.1 秒），最好語氣各不相同（平常、興奮、小聲……），每段標情緒。這些短錄音放在 `phrases/`，**不要**放進 `clean/` 或 `bgm/`。
4. 註明它是開場招呼、結尾招呼，還是一般口頭禪。

### 交付格式

```
交付/
  clean/                    沒有背景音樂
    ja/neutral/  ja/happy/  ja/angry/ …（每種情緒一個資料夾）
    ja/none/                情緒不確定
    en/…                    同上
    mixed/…                 日英夾雜，同上
  bgm/                      符合「有背景音樂的片段」全部條件的，結構和 clean/ 一樣
  phrases/
    やっほー/excited_1.wav, やっほー/soft_2.wav …
  clips.csv
  phrases.csv
  報告.txt
```

**檔名**：`日期_直播編號_開始秒-結束秒.wav`，例如 `20260815_abc123_3725.4-3801.0.wav`。

**clips.csv**（UTF-8，每個檔案一列；第一列是欄位名稱，**照下表的英文寫**，Voice Studio 會直接讀 file、emotion、lang 這三欄）：

| 欄位 | 內容 |
|---|---|
| file | 相對路徑，例如 `clean/ja/angry/20260815_abc123_3725.4-3801.0.wav` |
| stream | 直播標題 |
| date | 直播日期 |
| url | 直播網址（有的話） |
| start, end | 在原始直播裡的開始和結束時間（秒） |
| lang | `ja`、`en` 或 `mixed` |
| emotion | 情緒代碼之一（含 `none`） |
| bgm | `none`（放在 clean/）或 `low`（放在 bgm/，符合上面的全部條件） |
| transcript | 逐字稿（選填，規則見下） |
| notes | 任何需要人注意的事 |

**phrases.csv**：`phrase`（寫法）、`variants`（其他寫法，用「、」分隔）、`kind`（`opening`、`closing` 或 `catchphrase`）、`lang`、`count`（大約出現次數）、`file`、`emotion`。

**報告.txt**：各語言、各情緒的總時數（clean/ 和 bgm/ 分開算）；bgm/ 佔總量的比例；平常／強烈情緒／念稿的比例；用了哪些直播；排除最多的原因；找不到足夠素材的情緒或語言；出現少於 20 次的口頭禪。

### 逐字稿（選填）

有的話很有幫助，但要照下面的規則，不符合就寧可不寫：

- **照實寫，一字不改**：「えっと」「あの」「um」「like」、說錯重講、結巴都要寫出來。不要整理成通順的句子，不要翻譯。
- 日文用正常的漢字假名混寫；英文用一般拼字。
- 數字寫成實際念的樣子：念「にじゅうよじ」就寫「二十四時」或「にじゅうよじ」，不要寫「24時」。
- 笑聲、嘆氣這類不是字的聲音不要寫進逐字稿，寫在 notes。
- 聽不清楚的地方寫 `[?]`。

### 交付前自己檢查

- [ ] 每個檔案都只有目標說話者，沒有沒同意的人的聲音。
- [ ] 沒有唱歌、沒有機器人朗讀、沒有遊戲角色語音。
- [ ] 沒有降噪、沒有正規化、沒有轉 MP3。
- [ ] 每個檔案 10 秒到 10 分鐘，起訖在停頓上。
- [ ] 每個檔案都在對的語言和情緒資料夾裡，和 clips.csv 一致。
- [ ] 情緒只用規定的代碼；不確定的標 `none`。
- [ ] 一場直播不超過總量的 10%。
- [ ] 開場和結尾的固定招呼，在 clean/ 和 bgm/ 裡同一句不超過 5 次。
- [ ] bgm/ 裡的每個檔案：音樂很小聲、一直不變、沒有人聲歌詞、沒有音效；bgm/ 不超過總量的 30%。
- [ ] 口頭禪的短錄音只有口頭禪本身，而且只放在 phrases/。
- [ ] 如果你沒辦法真的聽聲音（只看字幕或逐字稿判斷），要在報告裡明說，哪些條件沒有實際確認。

（指示結束）

## B. 拿到結果之後：匯入 Voice Studio

1. **先抽查**：每個情緒資料夾隨便聽 2–3 個檔案，確認真的只有這個人、沒有音樂。
2. **匯入 clean**：在「匯入錄音」頁：
   - 「這些錄音裡主要是誰？」選這個人；「語言」選自動判斷；「情緒／風格」選不標記；
   - 在「直接匯入電腦上的資料夾」貼上 `clean` 的路徑，例如 `D:\交付\clean`，按「匯入」。
   - 子資料夾的名稱會自動變成標籤：`ja`、`en` 變成語言，`angry`、`happy` 這些變成情緒；`mixed` 和 `none` 不標。匯入後會顯示「已標上情緒：N 個來自資料夾名稱」，可以確認。
3. **匯入 bgm**（有的話）：
   - 先到「檢查音檔」頁，貼 `D:\交付\bgm` 並**勾「深入檢查」**。這些檔案的「背景音」一項本來就會是不通過，不用管它；看「**說話時底下的背景（深入）**」：比人聲**小 20 dB 以上**（通過或勉強可用）的才留，小不到 20 dB 的不要。其他項目（雜音、回音、破音…）照常要通過。
   - 檢查完，在那一批按「**匯入通過的**」→ 選「**背景音樂夠小聲的（bgm/ 用）**」→ 匯入。只會匯入符合上面條件的檔案，而且會自動去除背景音樂。
   - 建議先只用 clean 建一個資料集，匯入 bgm 之後再建一個，兩個都訓練 LoRA，在「模型」頁比較哪個比較像你。
4. **不要**直接匯入整個 `交付` 資料夾：`phrases/` 裡的口頭禪短錄音不是訓練素材，`bgm/` 也要另外勾去除背景音樂。
5. **登記口頭禪和開場招呼**：照 phrases.csv，在聲音頁的「口頭禪」卡片登記寫法和其他寫法，按「加入原音」把 `phrases/` 裡的短錄音加進去，選好情緒。
6. 匯入都處理完後，到「檢查資料」的「自動審核」選「**已審核過**」再按自動審核：篩選過的素材會直接核可，只有平台轉出來的文字拿不準的才留給你聽。

如果 AI 沒有照資料夾分，只給了 clips.csv：在匯入頁先按「上傳情緒清單」選 clips.csv，再匯入資料夾，情緒和語言會照清單標（`none` 視為不標）。

Voice Studio 不會讀 clips.csv 的逐字稿：它會自己用兩個語音辨識模型轉文字。逐字稿、報告和來源欄位是給你核對、追蹤素材來源用的。
