# 11. 用 Google Colab 訓練

訂了 Google AI Pro 或 Ultra 的話，每個月會附一筆 Colab 運算單位。Voice Studio 可以用它來訓練，不用租 RunPod。

| | RunPod | Google Colab |
|---|---|---|
| 費用 | 按小時付費（LoRA 一次約 1–2 美元，網路磁碟每月 10–21 美元） | 用訂閱附的運算單位 |
| 操作 | 按一下，全自動開機、訓練、關機 | 要自己在 Colab 按執行，分頁要開著 |
| GPU | 選了就有（沒貨會告訴你） | A100 不保證有，看當下供應 |
| 適合 | 所有訓練方式 | **VoxCPM2 LoRA**（完整微調的檔案太大，同步很慢） |

## 先知道的事

- **額度**：付費的 Google AI 方案每月都會存入一筆運算單位，但 Google 沒有公布是多少（媒體報導 Pro 約 200）。免費試用期間不算。到 Colab 的「設定 → 訂閱」可以看你的帳號有沒有。
- **GPU**：Google 只說「優先使用較快的 GPU」，沒有保證 A100。A100 每小時大約用 5–15 單位（第三方量測，Google 沒有公布）。
- **時間**：一次最多約 12 小時；Pro 沒有背景執行，**訓練時分頁要開著、電腦不能睡眠**。10 小時錄音的 LoRA 一次約 1–2 小時。
- **規則**：Colab 的使用規則禁止「製作深偽內容」。平台只訓練有同意紀錄的聲音，但最後由 Google 判斷，風險在你的 Google 帳號上（Gmail、雲端硬碟、訂閱都在同一個帳號）。

## 一次性設定（約 10 分鐘）

1. 安裝 **Google 雲端硬碟電腦版**（Google Drive for desktop），登入**和 Colab 同一個 Google 帳號**。
2. 打開 Voice Studio **設定 → Google Colab**：
   - 「我的雲端硬碟」的位置：平台會自動找，通常是 `G:\我的雲端硬碟` 或 `G:\My Drive`；
   - 資料夾名稱：預設 `VoiceStudio`；
   - 按「儲存並放入筆記本」。雲端硬碟裡會出現 `VoiceStudio/VoiceStudio-Colab.ipynb`。

## 每次訓練

1. **雲端訓練** 頁，「在哪裡訓練」選 **Google Colab**，引擎選 VoxCPM2、方式選 LoRA，按「放進雲端硬碟，準備在 Colab 訓練」。
2. 平台把資料（10 小時錄音約 3.5 GB）放進雲端硬碟資料夾，狀態變成「等你在 Colab 執行」。等雲端硬碟電腦版上傳完（工作列圖示不再轉圈）。
3. 在瀏覽器打開雲端硬碟，對 `VoiceStudio-Colab.ipynb` 按右鍵 → **開啟工具 → Google Colaboratory**。
4. 上方選單 **執行階段 → 變更執行階段類型** 選 **A100**（沒有就選 L4），按那一格左邊的 **▶**。第一次會要你允許存取雲端硬碟。
5. 分頁開著等它跑完。Voice Studio 的雲端訓練頁會顯示進度。完成後 Colab **自動斷線**，停止使用運算單位。
6. 模型同步回你的電腦後，平台自動安裝並評分各檢查點，之後和 RunPod 訓練的模型一樣使用。

## Gemini 建議的四個做法，平台怎麼做

| 建議 | Voice Studio 的做法 |
|---|---|
| 打包成一個檔案放雲端硬碟，在 Colab 複製到本機硬碟再解壓 | 一樣：整份資料是一個 `dataset.tar`，筆記本把它複製到 Colab 的 `/content` 再解開，訓練時不讀雲端硬碟上的零散小檔 |
| 去伴奏和切片在自己電腦做好 | 一樣：匯入時就在你的電腦切好句子；有背景音樂的勾「去除背景音樂」。建議裡的 RMVPE、`.pth`、`.index` 是 RVC（變聲）用的，VoxCPM2 不需要 |
| 權重直接存回雲端硬碟 | 訓練一結束，權重（`model.tar`）就**先**寫進雲端硬碟，然後才做試念樣本，所以之後出錯也不會遺失模型。訓練**途中**的檢查點留在 Colab 的硬碟上：中途斷線的話要重新執行，會從頭訓練 |
| 一格跑完、完成後自動斷線 | 一樣：筆記本只有一格，最後自動斷線（可以在表單取消勾選） |

## 出錯時

| 狀況 | 處理 |
|---|---|
| 筆記本說「找不到等待中的訓練」 | 雲端硬碟還沒同步完，等一下再執行；或確認資料夾名稱和設定一樣 |
| 筆記本說顯示記憶體不夠 | 換成 A100 或 L4 再執行一次（T4 只有 16 GB，不夠） |
| 一直在「等雲端硬碟同步 dataset.tar」 | 你的電腦還在上傳，保持開機、雲端硬碟電腦版開著 |
| 平台顯示「Colab 好像斷線了」 | 分頁被關掉、閒置太久或超過 12 小時。再執行一次筆記本，會從頭重新訓練 |
| 狀態停在「從雲端硬碟取回模型」 | 模型還在從雲端硬碟下載到你的電腦，確認雲端硬碟電腦版開著 |
| 想停止 | 在雲端訓練頁按「停止」，Colab 上的程式會在 30 秒內停下 |
| Colab 的輸出 | 雲端訓練頁的「紀錄」，或雲端硬碟 `VoiceStudio/jobs/<編號>/train.log` |

第一次在 Colab 跑真的引擎前，建議照〈雲端訓練〉的試跑清單，先用小資料集、1 個 epoch 跑一次。Colab 的 Python 和 PyTorch 版本會變動，這個模式還沒在真的 Colab 上測試過；遇到安裝錯誤，把「紀錄」最後幾十行貼給 Claude。
