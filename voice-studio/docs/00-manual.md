# 使用手冊（一步一步）

<a id="start"></a>

這份手冊從「我手上有一堆錄音」開始，一路教到「用我的聲音念任何台詞」。每一步都寫了**要去哪一頁**（藍色連結，點了會直接打開那一頁，手冊會留在右邊）和**在頁面的哪個位置**。

- 右上角的 **使用手冊** 按鈕可以打開或收起這個面板；拖曳面板左邊的邊線可以調整寬度。
- 面板上方的 ◎ 按鈕開著時，換到哪一頁，手冊就自動捲到那一頁的說明。
- 上方的「跳到…」選單可以直接跳到任何一步。

**整個流程**：

| 步驟 | 做什麼 | 在哪一頁 | 大約時間 |
|---|---|---|---|
| 0 | 安裝、啟動、更新 | 電腦上的資料夾 | 第一次 30 分鐘 |
| 1 | 建立「聲音」並填同意紀錄 | [聲音與同意](/voices) | 5 分鐘 |
| 2 | 整理錄音、決定情緒怎麼標 | 你的電腦 | 看檔案多少 |
| 3 | 匯入錄音 | [匯入錄音](/import) | 放著讓它跑（10 小時錄音約 1–3 小時） |
| 4 | 登記口頭禪（選做） | [聲音與同意](/voices) | 10 分鐘 |
| 5 | 檢查資料、建立資料集 | [檢查資料](/review) | 自動審核後約 1–3 小時 |
| 6 | 雲端訓練 | [設定](/settings)、[雲端訓練](/train) | 第一次設定 10 分鐘，訓練 1–3 小時 |
| 7 | 挑模型、加參考片段 | [模型](/models) | 15 分鐘 |
| 8 | 安裝本機合成引擎 | [設定 → 引擎](/settings#engines) | 10–20 分鐘（只做一次） |
| 9 | 用你的聲音念：打字、照著念、劇本 | [文字轉語音](/speak)、[照著念](/perform)、[劇本配音](/script) | 隨時 |

<a id="step-install"></a>

## 第 0 步：安裝、啟動、更新

### 第一次安裝

1. 下載程式 ZIP：
   https://github.com/ag8ai65566/ag8ai65566/archive/refs/heads/claude/sudowrite-novel-framework-2cmja7.zip
2. **先別解壓縮**：在 ZIP 上按右鍵 →「內容」→ 最下面勾「解除封鎖」→ 確定。
3. 解壓縮，打開裡面的 `voice-studio` 資料夾（`install.bat` 就在這個資料夾裡）。
4. 把 `voice-studio` 整個資料夾搬到**路徑沒有中文和空白**的地方，例如 `D:\voice-studio`。
5. 雙擊 `install.bat`。出現藍色「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」。看到「安裝完成」就好了。

詳細說明和需要的硬體：[〈安裝與啟動〉](01-install)。

### 每次啟動

- 雙擊桌面的 **Voice Studio** 捷徑（或資料夾裡的 `start.bat`）。瀏覽器會自動打開 `http://127.0.0.1:7860`。
- 要關閉時，關掉那個黑色視窗。雲端訓練不會因此中斷。

### 更新到最新版

1. 先關掉 Voice Studio 的黑色視窗。
2. 雙擊 `voice-studio` 資料夾裡的 **`update.bat`**。
   - 用 ZIP 安裝的也可以直接用：它會自己下載最新的 ZIP，覆蓋程式檔案，然後更新套件。
   - 你的錄音、模型、設定都在 `data` 資料夾，更新**不會動到**。
3. 看到「更新完成」後，再雙擊桌面的 Voice Studio。

<a id="step-voices"></a>

## 第 1 步：建立「聲音」並填同意紀錄

**頁面**：[聲音與同意](/voices)

每個要訓練的人都是一個「聲音」。沒有完整的同意紀錄就不能訓練，也不能合成。

1. 按頁面**右上角**的「新增聲音」。
2. 填：
   - **名稱**：例如「我」。
   - **這是誰的聲音？**：自己的選「我自己」；別人的選「其他人（需簽同意書）」。
   - **會說的語言**：勾日文、英文等。
3. 按「建立」。左邊清單會出現這個聲音，點它打開。
4. 往下找到 **「同意紀錄」** 卡片：
   - **簽名**：聲音本人的姓名；**同意日期**；**和你的關係**（本人／朋友…）。
   - **同意範圍**：勾「用錄音訓練語音模型」和「用模型產生新的語音」。
   - 別人的聲音：在「同意書」上傳簽名的檔案，或在「同意書存放處」寫放在哪裡。
   - 勾最下面黃色的確認框，按 **「儲存同意紀錄」**。卡片標題變成綠色「完整」就完成了。
5. （選做）**「參考聲紋」** 卡片：錄音裡常有其他人（來賓、合作對象）時，上傳 1–5 段「只有你在說話」的 5–30 秒錄音，按「加入聲紋」。平台會用它自動分出哪些句子是你。只有你一個人說話的錄音可以跳過。

> 只能訓練有同意的聲音。不要用這個平台模仿沒有同意的真人（例如直播主、藝人）。

## 第 2 步：整理錄音、決定情緒怎麼標

### 什麼樣的錄音最好

| 項目 | 建議 |
|---|---|
| 格式 | mp4、mkv、mov、wav、mp3、m4a、flac 都可以，影片也行（平台只取聲音） |
| 總長度 | 已核可的乾淨語音 **5–10 小時**最好；30 分鐘以上就能先試 |
| 品質 | 人聲清楚、不破音；背景音樂小聲或沒有（有的話匯入時勾「去除背景音樂」） |
| 人數 | 最好只有你；有別人也可以，匯入後再指定哪一群是你 |
| 內容 | 平常說話、各種情緒都有一些；日文英文都要說的話，各至少 2 小時 |

不用自己剪：平台會自動切成 2–15 秒的句子、轉成文字、分出誰在說話。

- 每一條的詳細說明和理由（開場招呼、口頭禪、情緒比例、不要收的東西…）：[〈理想的訓練音檔〉](13-ideal-audio)。
- 想請 AI 從直播幫你挑片段：[〈用 AI 先篩直播片段〉](10-ai-clips) 有一份可以整段貼給它的指示。它交回來的資料夾（`clean/ja/angry/…`）直接用方法 D 匯入就會標好。

### 情緒標籤：用檔名還是 Excel？兩種都可以

情緒標籤是給**整個檔案**的。標了之後，這個檔案切出來的每一句都會帶著這個情緒（之後還能逐句改）。

**不標也可以**：一般直播或雜談裡情緒混在一起，就先不標，到第 5 步「檢查資料」時用鍵盤 1–9 逐句標。

需要標的話，選一種最方便的方式：

| 你的情況 | 用這個方法 |
|---|---|
| 一批檔案**全部同一種情緒**（例如一個資料夾都是生氣的台詞） | **方法 A**：匯入頁直接選情緒 |
| 檔案不多，或你本來就會改檔名 | **方法 B**：在檔名加標籤 |
| 檔案很多、不想改檔名，或已經有一份清單 | **方法 C**：Excel／CSV 清單 |
| 已經把檔案分好資料夾（生氣／開心／…） | **方法 D**：資料夾名稱 |

可以填的情緒（中文或英文都行）：

| 中文 | 英文 | 中文 | 英文 |
|---|---|---|---|
| 平靜 | neutral | 笑著說 | laughing |
| 開心 | happy | 驚訝 | surprised |
| 興奮 | excited | 害怕 | scared |
| 生氣 | angry | 悄悄話 | whisper |
| 難過 | sad | 撒嬌 | teasing |
| 小聲 | soft | 念稿 或 旁白 | narration |

語言可以填：日文、英文、中文、自動（或 ja、en、zh）。

#### 方法 A：匯入頁選情緒（整批同一種）

把同一種情緒的檔案放在一起，匯入時在「情緒／風格」選那個情緒（第 3 步會教在哪裡選）。每種情緒分開匯入一次。

#### 方法 B：檔名標籤

在檔名裡加**括號**，括號裡寫情緒（也可以再加語言）：

```
0815直播[生氣].mp4
【開心】雜談回.wav
talk (angry).wav
【開心】【日文】歌回前聊天.mp4
```

或把情緒放在**最前面**，後面接底線 `_` 或減號 `-`：

```
生氣_0815.wav
excited-ending.mp4
```

注意：情緒要放在括號裡或最前面才算。像 `happy birthday.mp4`、`搞笑精華.mp4` 這種，檔名中間剛好有字的不會被當成標籤。

#### 方法 C：Excel／CSV 清單

1. 下載範本：[情緒清單範本（CSV）](/api/import-labels/template.csv)，用 Excel 打開（直接新建一個 Excel 也可以）。
2. 第一列是欄位名稱，至少要有 **檔名** 和 **情緒** 兩欄，**語言** 和 **備註** 可有可無：

   | 檔名 | 情緒 | 語言 | 備註 |
   |---|---|---|---|
   | 0815直播_開場.wav | 開心 | 日文 | |
   | 0815直播_輸了.wav | 生氣 | 日文 | |
   | english_chat.mp4 | 平靜 | 英文 | |
   | 雜談合集.mp4 | | 自動 | 留空＝不標 |

   - **檔名**要和檔案一模一樣，含副檔名（大小寫不用管）。只寫檔名，不用寫資料夾。
   - 情緒留空＝這個檔案不標。
   - 欄位名稱也可以用英文：file、emotion、language。
3. 存檔。可以存成 `.xlsx`，或「CSV UTF-8」。
4. 把清單交給平台，三種方式擇一：
   - 檔案名稱取叫 `情緒清單.xlsx`，**和錄音放在同一個資料夾**，用「匯入電腦上的資料夾」時會自動讀取；
   - 在匯入頁按「**上傳情緒清單**」；
   - 把清單和錄音**一起拖**進匯入頁的上傳框。
5. 讀取後會顯示「已讀取 N 個檔案」，有寫錯的格子會列出第幾列。

#### 方法 D：資料夾名稱

用「匯入電腦上的資料夾」或「選整個資料夾上傳」時，子資料夾的名字如果剛好是情緒（或語言），裡面的檔案就會標上：

```
D:\錄音\
  ├─ 生氣\   ← 裡面的檔案標「生氣」
  ├─ 開心\
  └─ 日文\   ← 裡面的檔案語言設成日文
```

#### 同一個檔案有好幾種標法時，聽誰的？

**清單 ＞ 檔名 ＞ 資料夾 ＞ 匯入頁選的**。例如清單寫「開心」、檔名寫 `[生氣]`，最後是「開心」。

## 第 3 步：匯入錄音

**頁面**：[匯入錄音](/import)

頁面分成三塊：左上「1. 匯入設定」、右上「2. 加入檔案」、下面「3. 處理狀態」。

### 3-1 左邊「1. 匯入設定」

1. **這些錄音裡主要是誰？**：只有你在說話就選你的聲音；有好幾個人或不確定就選「自動分辨」。
2. **語言**：不確定就選「自動判斷」。
3. **情緒／風格**：用方法 A 時才選；其他情況留「不標記」。
4. **每個檔案不同情緒？**（灰框）：
   - 用方法 C：按「**上傳情緒清單**」選你的 Excel／CSV；或按「**下載範本**」拿範本。
   - 讀取成功會變成綠色框，寫著讀到幾個檔案。不想用了按右上角的 ✕。
5. **去除背景音樂**：只有錄音裡有配樂或遊戲音效時才勾（處理比較慢，也會稍微改變音色）。

### 3-2 右邊「2. 加入檔案」，三種方式擇一

- **拖進來**：把檔案拖到虛線框裡（或點一下選檔）。情緒清單也可以一起拖。
- **選整個資料夾上傳**：按虛線框下面的「選整個資料夾上傳」，選一個資料夾。子資料夾名稱和資料夾裡的清單會一起套用。
- **直接匯入電腦上的資料夾**（檔案很多、很大時最推薦，不會複製檔案）：在下面的欄位貼上資料夾路徑，例如 `D:\錄音\2026`，按「匯入」。
  - 怎麼拿到路徑：在檔案總管打開那個資料夾，點上方的網址列，按 Ctrl+C 複製。
  - 子資料夾裡的檔案也會一起匯入；已經匯入過的會自動跳過，所以可以放心再按一次。

匯入後會顯示「已標上情緒：N 個來自清單、M 個來自檔名…」，可以確認標籤有沒有吃到。

### 3-3 下面「3. 處理狀態」

1. 每個檔案會依序：解碼 → 切句 → 辨認誰在說話 → 兩個語音辨識模型各轉一次文字並互相比對。進度條在「狀態」欄，右上角也看得到。
2. **情緒**欄可以直接改整個檔案的情緒（你之後逐句改過的不會被蓋掉）。
3. 選了「自動分辨」的檔案，處理完「誰」欄會出現「**N 段待指定**」按鈕：
   - 按下去，聽每一群的樣本；
   - 是你的那群選你的聲音；別人（來賓、遊戲角色）選「不是任何人（不用）」。
4. 狀態變成綠色「完成」就可以進下一步。處理時可以關掉瀏覽器分頁，只要黑色視窗開著就會繼續。

<a id="step-phrases"></a>

## 第 4 步：登記口頭禪（選做，但很推薦）

**頁面**：[聲音與同意](/voices) → 點你的聲音 → 往下找「**口頭禪**」卡片

登記之後，語音辨識會照你的寫法轉文字；合成時遇到口頭禪，會接上**你本人的原音**，聽起來最像。

1. 在「寫法」填口頭禪的標準寫法（例如 `えっとね`），「其他寫法」填常被寫錯的版本（逗號分隔），選語言，按「**登記**」。
2. 卡片會顯示錄音裡出現幾次、有幾種寫法。按「**統一寫法**」（或上方的「統一全部寫法」）把舊的寫法改成標準寫法。
3. 按「**加入原音**」：上傳一段只有這個口頭禪的錄音（0.2–10 秒），或從已切好的片段裡選一段剪出來。可以替原音標情緒，合成時會挑同情緒的那段。
4. 有模型之後，按「**檢查念法**」看模型自己念得像不像。

詳細說明：[〈聲音與同意〉](02-voices)。

## 第 5 步：檢查資料、建立資料集

**頁面**：[檢查資料](/review)

訓練品質主要取決於這一步：文字要和說的話**一字不差**（連「えっと」「um」也要寫），模型才學得到你的說話習慣。

### 5-1 先跑自動審核（幾小時的錄音一定要用）

1. 頁面**最上面**選你的聲音。
2. 右邊「**自動審核**」卡片：選「平衡」（資料 10 小時以上選「嚴格」），按「**自動審核 N 段待檢查的片段**」。
3. 跑完後卡片會出現兩個按鈕：
   - **① 需要你聽**：平台拿不準的，點了只顯示這些，一段一段聽；
   - **② 抽查自動核可的**：抽一小部分已自動核可的讓你確認。按 A＝沒問題，R＝排除。
4. 覺得自動審核不準：按「**復原自動審核**」全部改回待檢查（你自己決定過的不會變）。

### 5-2 逐段檢查的鍵盤快速鍵

點一下清單裡的片段，然後：

| 按鍵 | 作用 |
|---|---|
| 空白鍵 | 播放／停止 |
| J ／ K | 下一段／上一段 |
| A | 核可 |
| R | 排除 |
| 1–9 | 標情緒（1 平靜、2 開心、3 興奮、4 生氣、5 難過、6 小聲、7 笑著說、8 驚訝、9 害怕） |
| 0 | 清除情緒 |

- 文字不對：直接點文字修改（打字時快速鍵不會作用）。
- 上方的「**依情緒篩選**」可以只看某種情緒，確認各情緒夠不夠。
- 什麼該排除：有別人的聲音、笑到聽不清楚、破音、背景太吵、文字聽不出來的。

### 5-3 建立訓練資料集

右邊「**訓練資料集**」卡片：

1. 上面顯示已核可幾小時，以及「已核可的各情緒」（不到 5 分鐘的情緒會標黃色，想用那種語氣就再多找一些）。
2. 「最低分數」先用預設 0.50。
3. 按「**建立新的資料集**」。下面清單會多一個資料集。
4. 按那個資料集旁邊的「**訓練**」，會直接帶你到雲端訓練頁並選好它。

資料集是當下的快照：之後再改片段，不會影響已經建立的資料集（要用新的資料就再建一個）。

<a id="step-train"></a>

## 第 6 步：雲端訓練

訓練要在雲端的大顯示卡上跑。兩個選擇：

| | RunPod | Google Colab |
|---|---|---|
| 費用 | 按小時付費（LoRA 一次約 1–2 美元） | 用 Google AI Pro／Ultra 方案附的運算單位 |
| 操作 | 全自動：開機、訓練、下載、關機 | 要自己到 Colab 按一次執行，分頁要開著 |
| 適合 | 所有訓練方式 | VoxCPM2 LoRA |

### 6-1 第一次設定（擇一做）

**用 RunPod**：

1. 到 https://www.runpod.io 註冊並儲值（第一次 10–25 美元）。
2. 在 RunPod 建立網路磁碟（Storage → New Network Volume，150 GB），建立 API 金鑰和 S3 金鑰。每一步怎麼按：[〈雲端訓練〉](04-cloud)。
3. 回到 [設定](/settings)，第一張「**雲端 GPU（RunPod）**」卡片：貼上 API 金鑰、S3 Access Key、S3 Secret，各按「儲存」；再按「測試連線」，在清單點你的網路磁碟。
   - 金鑰只存在這台電腦的 Windows 認證管理員，不要貼到別的地方（包括聊天視窗）。

**用 Google Colab**：

1. 安裝「Google 雲端硬碟電腦版」，用和 Colab 同一個 Google 帳號登入。
2. 到 [設定 → Google Colab](/settings#colab)：確認「我的雲端硬碟」的位置（通常是 `G:\我的雲端硬碟`），資料夾名稱用預設 `VoiceStudio`，按「**儲存並放入筆記本**」。
3. 詳細說明和注意事項：[〈用 Google Colab 訓練〉](11-colab)。

### 6-2 開始訓練

**頁面**：[雲端訓練](/train) → 「**開始新的訓練**」卡片，由上往下填：

1. **訓練資料集**：選第 5 步建立的。
2. **引擎**：選 **VoxCPM2（推薦）**。
3. **訓練方式**：第一次選 **LoRA**。
4. **在哪裡訓練**：RunPod 或 Google Colab。
   - RunPod：選一張 GPU（會顯示價格和有沒有貨）。
5. 看一下預估時間和費用（或運算單位），勾確認。
6. 按「**開始雲端訓練**」（Colab 是「**放進雲端硬碟，準備在 Colab 訓練**」）。

> 第一次建議先用小資料集、1 個 epoch 試跑一次，確認整個流程都通，再用完整資料。試跑清單在[〈雲端訓練〉](04-cloud)。

### 6-3 用 Colab 的話，還要做這幾步

1. 雲端訓練頁的狀態變成「**等你在 Colab 執行**」，等工作列的雲端硬碟圖示不再轉圈（上傳完）。
2. 打開瀏覽器的 Google 雲端硬碟，在 `VoiceStudio/VoiceStudio-Colab.ipynb` 上按右鍵 →「開啟工具」→「Google Colaboratory」。
3. Colab 上方選單「執行階段」→「變更執行階段類型」→ 選 **A100**（沒有就選 L4）。
4. 按那一格左邊的 ▶，允許存取雲端硬碟。
5. 分頁開著、電腦不要睡眠。完成後 Colab 會自動斷線。

### 6-4 訓練中和訓練後

- 「**訓練紀錄**」卡片會顯示進度、預估剩餘時間；按「紀錄」看雲端的詳細輸出；按「停止」可以中止。
- 關掉 Voice Studio 不會中斷訓練，下次打開會自動接上。
- 完成後平台會自動下載模型，讓每個檢查點試念並評分。狀態變成完成就到下一步。

<a id="step-models"></a>

## 第 7 步：挑模型、加參考片段

**頁面**：[模型](/models)

1. 左邊點剛訓練好的模型。
2. 「**檢查點比較**」卡片：每個檢查點念同一批沒看過的句子，平台會算「相似度」（像不像你）和「念對程度」，標出「推薦」。在「試聽比較」聽聽看，挑你覺得最像的，按「**使用這個**」。
3. 「**參考片段**」卡片（很重要）：按「**加入**」，從已核可的片段選 5–12 秒、乾淨、文字正確的。
   - **每種常用情緒各加一段**（平靜、開心、生氣、小聲…），並在每段旁邊選情緒。
   - 合成時選了情緒，平台會自動挑那種情緒的參考片段，最能帶出語氣。「照著念」也是靠這個。
4. 想先試聽但還沒訓練：右上角「**建立免訓練模型**」用幾段錄音直接合成（像度比較低）。

<a id="step-settings"></a>

## 第 8 步：安裝本機合成引擎（只做一次）

**頁面**：[設定 → 引擎](/settings#engines)

1. 在 **VoxCPM2** 旁邊按「**安裝**」（約 5–8 GB，10–20 分鐘）。
2. 用 Qwen3-TTS 訓練的模型，再安裝 Qwen3-TTS。
3. 安裝在背景進行，進度在右上角和 [工作佇列](/jobs)。

顯示卡 10 GB（例如 RTX 3080）夠用；合成時請關掉遊戲、OBS 等吃顯示卡的程式。

<a id="step-speak"></a>

## 第 9 步：打字讓你的聲音念

**頁面**：[文字轉語音](/speak)

1. **模型**：選你的模型。
2. **文字**：輸入台詞。可以加 `[excited]`、`[whisper]` 這種方括號提示語氣。
3. **合成方式**：
   - **只用模型**：最自然的平常說話；
   - **參考音色**：搭配參考片段，最能控制情緒（建議）；
   - **完整複製**：連口音和節奏都照參考片段。
4. **情緒**：選一個（會挑那種情緒的參考片段和口頭禪原音）；或在「風格提示」描述語氣（英文最穩定，例如 `soft, slow`），也可以點下面的快速按鈕。「完整複製」模式會忽略風格提示。
5. 「產生幾個版本」選 2–3，按「**產生語音**」（或 Ctrl+Enter）。第一次要載入模型，約 30 秒。平台會用語音辨識檢查有沒有漏字，標出最好的一個。
6. 下面的歷史紀錄可以下載 WAV／MP3、加星號。

顯示卡記憶體不夠時，按右上角「**釋放顯示卡**」。

<a id="step-perform"></a>

## 第 10 步：照著念（丟一段錄音，用你的聲音學它的口氣）

**頁面**：[照著念](/perform)

給一段錄音，平台會聽出台詞、每句之間停多久、每句是大聲還是小聲、高還是低、快還是慢、句尾上揚還是下降，再用**你的模型**照樣念一次。聲音、音高和說話習慣還是你的；原音只拿來分析，**不會複製原音的聲音**。

開始前要有：一個訓練好的模型（第 6–7 步），最好在模型頁加好各情緒的參考片段。

### 10-1 上傳錄音

最上面「**1. 上傳錄音**」卡片：

1. 先選「**錄音的語言**」（不確定選自動）；有背景音樂就勾「去除背景音樂」。
2. 把錄音或影片拖進虛線框。**10–60 秒、人聲清楚**的效果最好；超過 5 分鐘只取前 5 分鐘。
3. 等「分析」跑完（幾秒到一分鐘）。做過的錄音會留在同一張卡片右邊的「之前的錄音」，點一下就能再打開。

### 10-2 確認台詞和口氣

中間「**2. 確認台詞和口氣**」卡片，最上面可以聽整段原音，下面每一句是一個小框：

| 欄位 | 意思和怎麼改 |
|---|---|
| 最左邊的勾 | 取消勾選＝這句不念 |
| 原音 ▶ | 聽這一句的原音（後面是秒數） |
| 台詞 | 辨識出來的文字。不對就直接改（點別處就會儲存） |
| 聽起來 | 和整段比較的結果，例如「大聲、偏高、句尾上揚」 |
| 情緒 | 平台猜的情緒。會挑**你自己那種情緒的參考片段**來念，最能帶出口氣；猜錯就換 |
| 風格提示 | 給引擎的英文說明（例如 `fast, loud`），可以改或清空；改過後可以按「用猜的」還原 |
| 之後停 | 這句念完停幾秒才念下一句 |

### 10-3 念出來

下面「**3. 用我的聲音念**」卡片：

1. **模型**：選你的模型。
2. **合成方式**：選「**參考音色**」（建議；需要模型頁有參考片段）。
3. **每句念幾次**：3 次是好的平衡。平台會挑長度最接近原音、而且沒念錯的那次。
4. 右邊四個選項（預設都開著）：
   - **保留原本的停頓**：句子之間停的時間照原音；
   - **對齊每句的長度**：每句稍微加快或放慢（最多約 ±20%），節奏接近原音，音高不變；
   - **跟著原音的大小聲**：原音大聲的句子也大聲一點（最多 ±6 dB）；
   - **口頭禪用原音**：台詞裡有你的口頭禪時接上你的原音。
5. 按「**用我的聲音念**」。完成後下面會並排顯示「原音」和「我的聲音」，可以下載 WAV／MP3。

### 10-4 哪一句不像？

- 在那一句改情緒或風格提示，再按那一句右下角「我的聲音」旁邊的 ↻，**只重念那一句**（其他句不變）。
- 標「可能念錯」的，是語音辨識聽到的和台詞不一樣：再重念一次，或把台詞改得更好念。
- 整體太平：把重要句子的情緒改成更明確的（例如興奮、生氣），並確認模型頁有那種情緒的參考片段。

<a id="step-script"></a>

## 第 11 步：劇本配音（整場對話）

**頁面**：[劇本配音](/script)

1. 「**1. 劇本**」：貼上 `角色 :: 台詞` 格式的劇本（按「載入範例」看格式）。`PAUSE :: 1.5` 會停 1.5 秒。
2. 「**2. 指定聲音**」：每個角色選一個模型（只能用有同意紀錄的聲音）。
3. 「**3. 合成**」：選「每句產生幾個版本」，按「**合成整場**」。完成後在「合成好的場景」下載整個檔案和逐句清單。

角色的語氣設定可以在 [角色預設](/characters) 匯入。詳細說明：[〈劇本配音〉](07-script)。

<a id="step-trouble"></a>

## 遇到問題

先看 [工作佇列](/jobs)：每個背景工作的進度和失敗原因都在這裡，失敗的可以按「重試」。

| 狀況 | 怎麼辦 |
|---|---|
| 匯入後很久沒動 | 看工作佇列；處理錄音一次只跑一個，前面的做完才輪到 |
| 情緒清單讀不到 | 第一列要有「檔名」欄；檔名要含副檔名；Excel 存成 .xlsx 或「CSV UTF-8」 |
| 檔名標籤沒吃到 | 情緒要放在括號 `[生氣]` 裡，或在最前面接 `_`（`生氣_xxx.wav`）；字要和上面表格的一樣 |
| 片段文字錯很多 | 匯入時語言不要選錯；登記口頭禪；在檢查資料修正 |
| 不能訓練 | 到 [聲音與同意](/voices) 確認同意紀錄是綠色「完整」 |
| RunPod 說沒有 GPU | 換一張卡或換資料中心再按一次 |
| 合成時「CUDA out of memory」 | 文字轉語音頁右上角「釋放顯示卡」，關掉其他吃顯示卡的程式 |
| 模型不能用、說要安裝引擎 | [設定 → 引擎](/settings#engines) 安裝對應的引擎 |
| 照著念的台詞斷錯句 | 改「台詞」和「之後停」，或換一段停頓比較清楚的錄音 |
| 照著念太不像原音的口氣 | 每句的情緒改明確一點；模型頁補各情緒的參考片段 |
| 更新失敗 | 確認網路正常、Voice Studio 已關閉，再執行一次 `update.bat` |

其他常見問題：[〈常見問題〉](09-faq)。
