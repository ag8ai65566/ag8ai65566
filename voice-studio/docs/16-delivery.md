# 16. 交付資料夾（一鍵匯入）

錄音已經切好、標好情緒、附了逐字稿和清單時，用「交付資料夾」頁一次匯入：平台照資料夾名稱把每段錄音放到對的位置，匯入完直接建立資料集，按一下就到雲端訓練頁（資料集已選好）。

> **只能匯入有完整同意紀錄的聲音。** 沒有同意紀錄的聲音，這一頁的「一鍵匯入」按不下去，後端也會拒絕。藝人、主播、VTuber 等沒有親自同意的人，不能用這個功能（見〈聲音與同意〉）。

## 一、怎麼用

1. 先到 [聲音與同意](/voices) 建立聲音，填好同意紀錄（卡片變綠色「完整」）。
2. 打開 [交付資料夾](/delivery)，在「資料夾路徑」貼上路徑，按 **掃描**：
   - 貼**上層資料夾**（例如 `E:\交付總覽`）：列出裡面每一個人；
   - 貼**一個人的資料夾**：只列這個人。
   有「交付」「常用語」「素材庫」其中一個子資料夾的，就算一個人。
3. 每個人一張卡片，顯示會放進訓練的片段數、語言和情緒分布、口頭禪和聲音標籤數，以及哪些不會放進去（沒有逐字稿、重複、句子不完整）。
4. 「匯入到哪個聲音」：名字和資料夾一樣的聲音會自動選好。按 **一鍵匯入**。
5. 完成後按 **用這份資料集訓練**，到雲端訓練頁確認費用、開始訓練。

同一個資料夾可以再匯入：已經匯入過的錄音會跳過（你在「檢查資料」改過的不會被蓋掉），只加新的。

## 二、每個資料夾放到哪裡

```
<人>\
├── 交付\
│   ├── clean\<語言>\<情緒>\              → 訓練片段（背景安靜）
│   ├── bgm\<語言>\<情緒>\                → 訓練片段（背景有小聲音樂，標「背景有小聲的音樂」）
│   ├── clean_去背景音樂\<語言>\<情緒>\   → 有對應 bgm 片段時取代它（標「去過背景音樂」）
│   ├── phrases\<口頭禪>\                 → 口頭禪的原音
│   ├── clips.csv                         → 逐字稿（transcript）、語言、情緒
│   └── phrases.csv                       → 口頭禪的其他寫法（variants）
├── 常用語\
│   ├── 原音\<類型>\<編號>_<句子>\        → 口頭禪的原音，也當訓練片段
│   ├── 已去背景音樂\<類型>\<編號>_<句子>\
│   └── 常用語.csv                        → 原文、句子完整度、聲紋相似度
└── 素材庫\
    ├── 原音\聲音\<標籤>\                  → 聲音標籤，例如 [笑聲]、[打噴嚏]
    ├── 原音\<其他大類>\<標籤>\            → 有文字的當訓練片段，情緒照標籤（例如「開心」→ 開心）
    └── tags.csv                          → 文字
```

| 來自 | 變成 | 怎麼決定 |
|---|---|---|
| 檔名 `<日期>_<影片ID>_<開始秒>-<結束秒>` | 同一部影片的片段算同一段錄音 | 影片有 5 部以上時，驗證集整部影片一起保留，不會用同一場直播的相鄰句子考自己 |
| `<語言>` 資料夾 | 語言 | `en`、`ja`；`mixed` 不指定（讓引擎自己判斷） |
| `<情緒>` 資料夾或檔名開頭 | 情緒標籤 | neutral、happy、excited、angry、sad、soft、laughing、surprised、scared、whisper；`none` 不標 |
| clips.csv 的 transcript | 片段文字 | 沒有逐字稿的片段不放進訓練 |
| 常用語.csv 的句子完整度 | 能不能用 | 「不完整」或低於 0.9 的不當訓練、也不當口頭禪原音 |
| 常用語.csv 的聲紋相似度 | 口頭禪原音的挑選順序 | 先挑完整的、相似度高的，盡量每種情緒一段 |

**重複的片段**：同一部影片、時間重疊超過一半的，只留一段。順序是「交付」優先，然後是「常用語」，最後是「素材庫」。

**不放進訓練的**：`delivered.json`、`rejected.json`、`selfcheck.json`、`報告.txt` 只是紀錄，不會讀進來。

## 三、匯入設定

| 設定 | 預設 | 說明 |
|---|---|---|
| 有背景音樂的片段 | 用去背景音樂的版本 | 有對應的 `clean_去背景音樂` 檔時用它，沒有就用原音。也可以選「用原音」或「不要用」 |
| 每句口頭禪／聲音標籤最多放幾段原音 | 8 | 合成時依情緒挑一段；太多只是佔空間 |
| 常用語的錄音也當訓練資料 | 開 | 句子不完整的不會放進去 |
| 通過檢查的片段直接核可 | 開 | 爆音、分數太低的留在「檢查資料」等你聽 |
| 匯入後建立資料集 | 開 | 用這個聲音所有已核可的片段建立 |

聲音標籤一律優先用「原音」：去背景音樂最容易把呼吸、氣音一起去掉。口頭禪和常用語跟著上面的背景音樂設定。

## 四、常見問題

- **「一鍵匯入」是灰的？** 選的聲音同意紀錄不完整。到〈聲音與同意〉補好簽名、日期、同意範圍；「其他人」還要上傳同意書或寫明紙本放在哪裡。
- **找不到人？** 路徑要指到「交付」「常用語」「素材庫」的上一層，或更上層。
- **超過 60 字的常用語？** 口頭禪最多 60 字，太長的句子只當訓練資料，結果裡會列出來。
- **有的原音沒有加入？** 去掉前後靜音後要 0.2–10 秒，不合的會在結果裡列出來。
