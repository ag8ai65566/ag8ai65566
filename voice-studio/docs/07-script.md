# 7. 劇本配音與角色預設

## 劇本格式

和 novel-lab 的場景格式一樣：

```
@@scene 屋上の練習
@@date 2026-10-06
STAGE :: 夕方、屋上。風が少し強い。
我 :: [calm] ねえ、もう一回だけ合わせてみない？
ROMAJI :: Nē, mō ikkai dake awasete minai?
PAUSE :: 0.6
友達 :: [bright, laughing] いいよ。でも今度は笑わないでね。
```

| 行 | 作用 |
|---|---|
| `角色 :: 台詞` | 會被念出來。方括號裡是語氣提示 |
| `PAUSE :: 秒數` | 插入停頓 |
| `STAGE ::`、`SFX ::`、`NOTE ::` | 舞台說明、音效、備註，不念 |
| `ROMAJI ::`、`GLOSS ::` | 附在上一句的羅馬拼音、翻譯，會出現在逐句清單 |
| `Narrator ::` | 旁白，目前略過 |
| `@@`、`#` 開頭 | 標題與註解 |

## 合成整場

1. **劇本配音** 頁貼上劇本（按「載入範例」可以看格式）。
2. 每個角色選一個模型、語言、合成方式；可以再加整體風格提示。
3. 設定每句幾個版本、句子間隔，按 **合成整場**。
4. 完成後在下方「合成好的場景」播放整段、下載，並逐句聽（每句都標了念對 %）。不滿意的句子，可以複製到〈文字轉語音〉單獨重做。

劇本和角色分配會記在瀏覽器裡，下次打開還在。

## 角色預設

**角色預設** 頁可以從 novel-lab 的表演單（`novel-lab/projects/holoen/export/elevenlabs`）匯入每個角色的：

- 台詞語言（JP 成員一律日文）；
- 常用語氣標籤、各種情境的標籤與示範句；
- 念法注意事項、要避免的念法。

**角色預設只有「怎麼演」，沒有任何人的聲音。** 平台不會、也不能用來模仿藝人或角色原本的聲音。你可以把**自己有同意紀錄的模型**指定給某個角色（例如你自己、或同意參與的朋友來「演」這個角色）；之後劇本裡出現這個角色名稱時，就會自動帶入那個模型和語言。

在文字轉語音頁選「角色預設」，也會套用語言和常用語氣；點情境按鈕可以直接換成那個情境的語氣。
