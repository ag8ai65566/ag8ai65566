# 6. 文字轉語音

**文字轉語音** 頁。第一次合成要把模型載入顯示卡，大約 30 秒；之後每句幾秒。

想讓你的聲音照著一段錄音的台詞和口氣念，用[〈照著念〉](12-perform)。

## 基本操作

1. 選模型。
2. 輸入文字（一次最多 2000 字；長篇請用〈劇本配音〉一句一句合成，品質比較穩）。
3. 選合成方式（見下）。
4. 「產生幾個版本」選 2–3，按 **產生語音**（或 Ctrl+Enter）。
5. 平台會用語音辨識聽每個版本，標出 **念對 %** 和 **最好** 的那個。下載 WAV 或 MP3。

所有產生過的語音都在右邊「紀錄」，可以收藏（☆）。

## 三種合成方式

| 方式 | 怎麼運作 | 什麼時候用 |
|---|---|---|
| **只用模型** | 訓練好的模型自己說 | 一般用途；可以加風格提示 |
| **參考音色** | 再給一段參考錄音帶音色 | 想讓某種語氣更明顯（選那種語氣的參考片段） |
| **完整複製** | 參考錄音＋它的逐字稿，模型「接著」那段錄音說下去 | 要最像本人：口音、節奏、句尾習慣都最接近。**會忽略風格提示** |

想要「最完美的複製」：訓練過的 VoxCPM2 模型 ＋ 完整複製 ＋ 一段和目標語氣接近的參考片段。

可用的方式依模型而定：VoxCPM2 三種都有；訓練過的 Qwen3-TTS 只有「只用模型」；免訓練模型只有「參考音色」和「完整複製」。

## 情緒

「情緒」選一種（例如生氣），平台會：

- 自動選那種情緒的**參考片段**（「參考音色」和「完整複製」模式；你也可以再手動換）；
- 口頭禪用原音時，挑那種情緒的**原音**。

選「自動」時，平台從風格提示或文字裡的 [angry] 這類標籤判斷。參考片段要先在模型頁標好情緒（見〈模型與檢查點〉）。

## 口頭禪用原音

在聲音頁登記了口頭禪、而且加了原音之後，文字裡出現那個口頭禪時，平台會換成**本人的錄音**：

| 口頭禪在哪裡 | 怎麼處理 |
|---|---|
| 整句就是口頭禪（例如「やっほー！」） | 直接用原音 |
| 句子開頭（例如「やっほー！今日もやるよ」） | 原音之後的部分，VoxCPM2 會用「完整複製」接著原音說下去，所以銜接自然；Qwen3-TTS 和其他情況則照一般方式合成再接起來 |
| 句子中間或結尾 | 前後的部分照一般方式合成，中間接上原音 |

- 原音的音量會自動調成和合成的部分一致，停頓長短依標點決定（「、」短、「。！？」長）。
- 有好幾段原音時，挑和這句情緒相同的；每個版本會輪流用不同的原音。
- 每個版本旁會標「含原音」。不想用時，取消勾選「口頭禪用原音」。
- 句中、句尾的接縫可能聽得出來，請試聽；如果不自然，可以把句子拆開，或改用模型自己念。
- 用了原音的成品仍然標記為合成語音。

## 風格提示

在「只用模型」和「參考音色」模式可以描述語氣，例如：

- `calm, slightly slower`
- `excited, energetic`
- `soft, whispering`
- `annoyed, sharp`

用英文描述通常最穩定；按下面的按鈕可以快速加入。文字裡也可以直接寫方括號標籤，例如 `[excited] やった！` 或 `[害羞] もう…`，平台會把它轉成風格提示（novel-lab 的 ElevenLabs 標籤也通用，見下面的「可以用的標籤」）。

風格提示是「建議」，不是保證：效果取決於訓練資料裡有沒有那種語氣。

## 長文・逐句調整

文字很長、或想一句一句調語氣時，用頁面上方的「**長文・逐句調整**」（最多 20,000 字）。

1. 貼上文字，按「**分句**」。平台會按段落和句號（。！？.!?）切開；太長的句子在逗號處再切，太短的（「えっと。」「Yes.」）會跟旁邊那句合在一起，念起來比較自然。
   - 空一行＝換段落，停 0.8 秒；同一段裡的句子之間停 0.35 秒。每一句的「之後停」都可以改。
2. 每一句都可以單獨設定：
   - **情緒**：選了就挑你自己那種情緒的參考片段來念，最能帶出語氣；
   - **風格提示**：例如 `slow, gentle`；
   - **之後停**：這句念完停幾秒；
   - 取消勾選＝這句不念。
3. 在「3. 產生」選模型、合成方式（建議「參考音色」）、**預設情緒**和**預設風格提示**（給沒有自己設定的句子），按「**全部產生**」。
4. 每一句都可以按「聽」單獨聽；不滿意的，改情緒或風格後按那一句的「**重念**」，其他句不變，整篇會重新接好。
5. 整篇可以下載 WAV／MP3。

**誰說了算**：那一句自己選的情緒 ＞ 句子裡的 `[標籤]` ＞ 「3. 產生」的預設情緒。寫在**段落開頭**的標籤會套用到整段（像 ElevenLabs 的寫法）：

```
[excited] やっほー！今日はね、すごいニュースがあるの。聞いて聞いて！

[whispers] これはまだ秘密なんだけど…誰にも言わないでね。
```

### 可以用的標籤

一共 170 多個，分成 16 類：開心・正面、生氣・不滿、難過・哭腔、害怕・緊張・驚訝、害羞・撒嬌・調情、冷淡・認真・自信、疲倦・想睡・身體狀況、音量・距離、速度・節奏・音調、說話習慣（結巴、猶豫、越說越小聲、嘀咕、自言自語…）、角色・用途（旁白、說故事、新聞播報、實況、廣告…）、笑聲、哭聲、呼吸、其他聲音（咳嗽、清喉嚨、打噴嚏、打哈欠、哼歌、嘖、尖叫…）、停頓。中文、英文、日文的寫法都可以（`[害羞]` = `[embarrassed]` = `[照れて]`）。

文字框下面按「**標籤**」可以搜尋、點一下插入；完整清單和每個標籤的效果見[〈標籤一覽〉](14-tags)。

- 標籤管**它後面的字，到下一個標籤為止**：`[開心] やった！[難過] でも…` 前半開心、後半難過（平台會在換標籤的地方分段合成再接起來）。
- `[停頓]`、`[停頓 1.5秒]`、`[pause 2s]` 是**真的靜音**。
- 聲音類標籤（嘆氣、笑聲、咳嗽…）沒有原音時只是「語氣」；放了你自己的原音（下面的聲音標籤）才會真的發出那個聲音。
- 最有效的方法：在模型頁為常用情緒各加一段**你自己那種語氣的參考片段**，再用「參考音色」模式。標籤會自動挑那種情緒的參考片段。

### 真的喘氣、嘆氣聲：聲音標籤

要聽到**真的**吸氣、嘆氣、喘氣、嬌喘，而不只是語氣，用聲音標籤：在聲音頁登記 `[喘氣]` 並放進你自己錄到的聲音（平台可以幫你從匯入的錄音裡找，見〈聲音與同意〉的「聲音標籤」）。之後：

- 文字裡寫 `[喘氣]` 的位置，會播你的原音，前後的字照常合成，例如 `[大口吸氣] ねえ、聽我說。[嘆氣] 算了。`
- 文字框下面的綠色按鈕（你的原音）和「標籤」選單裡的綠色標籤，會把標籤插在游標的位置。
- 一個標籤收了好幾段時，會挑和這一句情緒相同的那段；同一句產生好幾個版本時會輪流用。
- 播原音的標籤不會再變成語氣提示；想要整句都喘著說，另外在風格提示寫 `breathless`。
- 長文模式裡，寫在段落開頭的聲音標籤（`[吸氣]` `[嘆氣]` `[喘氣]` `[笑]`…）只用在第一句，不會每一句都出現；`[excited]` `[whispers]` 這種「怎麼說」的標籤才會套用到整段。
- 「口頭禪用原音」取消勾選時，聲音標籤也只當語氣提示。

## 日文小技巧

- 讀音容易錯的字（人名、地名、多音字）可以直接寫成平假名；常用的詞放進 **設定 → 讀音字典**，以後每次合成都會自動替換。
- 句尾的「。」「！」「？」「…」會影響語調，照想要的語氣寫。
- 很長的句子拆成幾句，用劇本配音接起來，比一次念完穩定。

## 種子

同一段文字、同一個種子，會產生一樣的結果。找到喜歡的版本時，記下它的種子（每個版本上都有顯示），之後可以重現。

## 釋放顯示卡

平台一次只把一個模型放在顯示卡上。要玩遊戲或用其他 AI 工具前，按右上角「釋放顯示卡」。

## 合成語音的標記

每個合成檔案的中繼資料都寫著「AI-generated speech」。公開發布時，也請在說明裡註明是合成語音。
