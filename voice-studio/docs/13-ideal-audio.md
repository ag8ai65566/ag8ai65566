# 13. 理想的訓練音檔

一句話：**只有你一個人、乾淨、沒有後製、自然地說話，而且各種情緒和場合都有。** 多樣比時數重要；聲音品質壞掉的部分，事後救不回來。

下面每一項都寫了「理想的樣子」和「為什麼」。用 AI 幫你從直播挑片段的話，[〈用 AI 先篩直播片段〉](10-ai-clips) 有一份已經照這些原則寫好、可以直接貼給它的指示。

## 一、聲音本身（最重要）

| 條件 | 理想的樣子 | 為什麼 |
|---|---|---|
| 人數 | 從頭到尾只有你在說話，沒有別人插話或同時說話 | 模型會把別人的聲音混進你的音色 |
| 背景 | 沒有音樂、遊戲音效、斗內提示音、播放的影片 | 背景聲會被當成你聲音的一部分學進去 |
| 背景音樂 | 真的避不開時：比人聲小 20 dB 以上、同一首曲子音量不變、**音樂裡沒有人聲歌詞**、沒有音效；最多佔總量 30%，匯入時勾「去除背景音樂」 | 分離能救，但會稍微改變音色（高音變薄、一點水聲）；歌詞的人聲會被當成你留下來。能不用就不用 |
| 雜音 | 人聲比背景大 25 dB 以上（安靜房間、近距離收音） | 平台自動核可的門檻是 18 dB（平衡）／22 dB（嚴格），低於 10 dB 直接排除 |
| 回音 | 嘴巴離麥克風近、房間不空曠 | 回音會被學成音色，合成出來像在浴室裡說話 |
| 破音 | 大聲的地方也不破音（音量表不碰頂） | 破音是刺耳的失真，平台在超過 0.1% 取樣破音時就標記 |
| 音量 | 小聲的地方還聽得清楚，大聲的地方不破音 | 太小聲雜音比例高；太大聲會破音 |
| 後製 | **原樣**：不要降噪、AI 人聲加強、音量正規化、壓縮器、EQ、殘響、變聲器 | 處理器的痕跡（降噪的水聲、壓縮的扁平）會被當成你的聲音學走 |
| 格式 | WAV 或 FLAC，44.1 或 48 kHz | 每轉一次 MP3 就再損失一次。直播下載的檔案本來就是壓縮過的，保持原檔、不要再轉 |
| 麥克風 | 大部分用同一支主麥克風，其他麥克風的少量收一些 | 合成出來的音質會像主力麥克風；少量別的麥克風讓模型不把某一支的特色當成你 |

## 二、長度和切法

- **匯入的檔案**：10 秒到 10 分鐘的連續說話就好，整場直播也可以。平台會自己切成 2–15 秒（目標 8 秒）的句子，你不用切到每一句。
- **最理想的一句**：3–12 秒、一個完整的意思，在停頓處開始和結束。太短（2 秒以下）學不到語調；太長（15 秒以上）會被切開。
- **檔案的開頭和結尾**：切在停頓上，前後留 0.3–0.5 秒自然的空白。不要切到字，不要加淡入淡出。
- **句尾要完整**：說到一半被切掉的句子，模型會學到奇怪的收尾。

## 三、內容

### 自然說話比念稿重要

你想讓模型怎麼說話，就給它那樣的說話。想要直播的語氣，就用直播的聊天訓練；只給念稿，它只會念稿。

### 情緒和場合的分配

| 類型 | 建議比例 | 例子 |
|---|---|---|
| 平常說話（平靜、開心） | 50–60% | 一般雜談、說明規則、聊天 |
| 強烈的情緒（興奮、生氣、難過、害怕、驚訝、撒嬌、小聲、悄悄話、邊笑邊說；有的話再加不耐煩、哭腔、緊張、害羞、嫌棄、疲倦、大喊、認真、冷淡、得意、諷刺、疑惑） | 20–30% | 遊戲贏了或輸了、恐怖遊戲、深夜雜談 |
| 念稿、念留言 | 10–20% | 念斗內留言、念預先寫好的文字 |

- 每一種你想用的情緒，**至少 5 分鐘**（約 50 句），10 分鐘以上更好。不到 5 分鐘時平台會提醒。
- **分散**：不同日期、不同類型的直播（雜談、遊戲、企劃、深夜）。同一場直播最多佔總量的 10%。
- **句型多樣**：問句、感嘆、長句、短反應、列舉、解說都要有；不要全是同一個話題。模型要聽過各種音和語調的組合，念新句子才自然。
- **語言**：要讓它說哪種語言，就要收那種語言。日文、英文各至少 2–3 小時；你平常會日英夾雜的話，也收一些夾雜的。

### 保留你的說話習慣

「えっと」「あの」「um」「like」、說錯重講、結巴都是你的習慣，**留著**。逐字稿也要照實寫出來，模型才學得到。

### 不要收的

| 不要 | 原因 |
|---|---|
| 唱歌、哼歌 | 不是說話，模型會亂掉 |
| 別人說話、或和別人同時說話 | 會混進別人的聲音；沒有同意的人不能收 |
| 機器人朗讀、遊戲角色語音、播放的影片 | 不是你 |
| 模仿別人、角色扮演的怪聲、刻意變聲 | 不是你自然的聲音 |
| 大笑、尖叫、哭喊為主，幾乎沒有字 | 沒有對得上的文字（邊笑邊說、字還清楚的可以收） |

單獨的嘆氣、喘氣、吸氣、嬌喘不能當訓練資料（沒有文字），但可以拿來當**聲音標籤**的原音：每種 2–5 段、0.2–10 秒、只有那個聲音、背景安靜，另外放一個資料夾（例如 `sounds/喘氣/`），之後在聲音頁的「聲音標籤」用「加入原音 → 上傳檔案」加入。已經匯入的錄音裡也可以讓平台幫你找（聲音標籤卡片的「掃描我的錄音」）。
| 破音、斷訊、麥克風被碰到 | 瑕疵會被學走 |
| 長時間沉默、只有打字聲或遊戲聲 | 沒有說話 |

## 四、開場招呼和口頭禪

### 開場、結尾的固定招呼

「こんばんは〜○○です」「おつ〜」這類開場和結尾的固定台詞，是你最有辨識度的一句，但也最容易重複幾百次。

- **訓練資料裡，同一句（含小變化）最多 5 次**。太多的話，模型念別的句子也會帶著招呼的語調。
- 把它**登記成口頭禪**，準備 2–5 段原音（不同語氣）。合成時遇到這句，平台直接接上你的原音，比模型自己學更像。

### 口頭禪

找出 3–10 個最有特色的（招呼語、反應詞、固定句型都算）：

1. 寫法和其他寫法（例如「やっほー」「ヤッホー」「やっほ〜」），讓語音辨識統一寫法。
2. 在訓練資料裡**出現 20 次以上**，模型才學得到它的念法；不到 20 次的，合成時用原音比較保險。
3. 2–5 段**只有這個口頭禪**的短錄音（0.3–5 秒），語氣各不相同，各標一個情緒。

登記的位置：[〈使用手冊〉](00-manual) 第 4 步。

## 五、文字（逐字稿）

- **你不用準備逐字稿**：平台用兩個不同的語音辨識模型各轉一次並互相比對，一致度 88% 以上（嚴格模式 95%）才自動核可。
- 但最後的文字要符合這些原則（在「檢查資料」修正時也一樣）：
  - 和說的話**一字不差**，包括 えっと、um、說錯重講；不要整理成通順的句子。
  - 數字寫成實際念的樣子（念「にじゅうよじ」就不要寫「24時」）。
  - 笑聲、嘆氣這類不是字的聲音不寫進文字。
- 匯入時**語言要選對**：知道是日文或英文就直接選，辨識會保留口頭禪；選「自動」時口頭禪比較容易被省略。

## 六、情緒標籤

- 標籤**不會讓模型學得更好或更差**：訓練格式沒有情緒欄位，模型是從聲音本身學會你生氣時怎麼說話。
- 標籤的用處：看每種情緒夠不夠、為每種情緒留參考片段、合成和「照著念」時挑對語氣。
- 整個檔案**六成以上是同一種情緒**才整檔標；混在一起的不標，到「檢查資料」逐句按 1–9。
- 怎麼標（資料夾名稱、檔名、Excel 清單）：[〈使用手冊〉](00-manual) 第 2 步。

## 七、要多少

| 已核可的乾淨語音 | 能做什麼 |
|---|---|
| 30 分鐘以下 | 先用「免訓練模型」試聽 |
| 30 分鐘–5 小時 | 可以跑 LoRA 確認流程，效果有限 |
| **5–10 小時** | **建議目標**，最像本人 |
| 10 小時以上 | 只有帶來新的語氣、場合或語言時才有幫助 |

檢查時通常會排除一部分。用 AI 從直播挑片段的話，請它交 **12–14 小時**，檢查完大約剩 8–10 小時。

## 八、參考片段（合成用，不是訓練用）

訓練完成後，在「模型」頁為每種常用情緒各加一段參考片段：**5–12 秒、乾淨、文字正確、語氣明確**。合成時選了情緒、劇本寫了 `[angry]`、或用「照著念」，平台都靠這些片段帶出那種語氣。

## 九、平台會幫你檢查的項目

自動審核用這些訊號決定核可、排除或交給你聽：

| 檢查 | 理想 |
|---|---|
| 兩個辨識模型的一致度 | 88% 以上（嚴格 95%） |
| 雜音（訊噪比） | 18 dB 以上（嚴格 22 dB） |
| 破音 | 幾乎沒有（超過 0.1% 標記，超過 1% 排除） |
| 聲紋 | 整段都像你，中途沒有換人 |
| 語速 | 日文每秒 1–14 個字、英文每秒 0.6–5.5 個字（太離譜代表文字和聲音對不上） |
| 長度 | 1–30 秒 |

## 十、用「檢查音檔」頁自動檢查

第一到第二節（聲音本身）可以交給平台檢查：到 **檢查音檔** 頁丟進錄音或貼資料夾路徑，每個檔案會得到「通過／勉強可用／不通過」，並列出有問題的時間點。

| 項目 | 通過 | 勉強可用 | 不通過 |
|---|---|---|---|
| 背景音（音樂、音效、別人說話） | 停頓時聽不到（比人聲小 42 dB 以上，或只有零星一點） | 停頓中 2% 以上的時間聽得到 | 停頓中 5% 以上的時間有，而且只比人聲小不到 30 dB |
| 雜音（底噪、風扇） | 人聲比背景大 25 dB 以上 | 18–25 dB；或有電源嗡嗡聲 | 不到 18 dB；或嗡嗡聲只比人聲小不到 30 dB |
| 回音 | 殘響 0.35 秒以下 | 0.35–0.6 秒 | 超過 0.6 秒 |
| 破音 | 說話時間的 0.01% 以下 | 0.01%–0.1% | 超過 0.1% |
| 音量 | 說話時 −35 dBFS 以上 | −45 到 −35 dBFS | 低於 −45 dBFS |
| 音質（頻寬） | 聲音到 13 kHz 以上 | 7–13 kHz | 不到 7 kHz（電話音質） |
| 後製痕跡 | 停頓有自然的底噪 | 停頓或字和字之間是數位的完全無聲（降噪、噪音閘門） | — |
| 斷訊 | 沒有 | 1–2 處 | 3 處以上 |
| 說話時底下的背景（深入檢查） | 分離後剩下的比人聲小 30 dB 以上 | 小 20–30 dB | 小不到 20 dB |

它是怎麼聽的：

- 先找出哪裡在說話。**停頓的時候**，背景就單獨露出來：每半秒量一次，分辨是穩定的底噪（風扇、沙沙聲）、50／60 Hz 的電源嗡嗡聲、像說話的聲音（別人、影片），還是有音高、會變化的聲音（音樂、遊戲音效）。音樂很少剛好在你說話時停下來，所以停頓幾乎都抓得到。
- 回音看每句話結尾之後聲音消失得多快。
- 頻寬看高音在哪裡突然沒了（MP3／AAC 壓縮很重或取樣率太低時會這樣）。
- 深入檢查用人聲分離（BS-RoFormer）把你的聲音拿掉，量剩下的有多大聲。分離本身會留下一點點，所以這個數字當參考。

門檻用合成的測試錄音校正過（乾淨人聲分別加上音樂、音效、白噪音、風扇聲、嗡嗡聲、不同大小的房間回音、破音、電話音質）。真實的直播錄音大多有背景音樂或遊戲聲，通常會被判成不通過，這是正常的。

## 十一、交出去前的快速檢查

- [ ] 隨便聽幾段：只有你？沒有音樂？沒有回音？沒有破音？
- [ ] 沒有降噪、正規化、轉 MP3 這類處理。
- [ ] 平常、強烈情緒、念稿的比例大約 6：3：1；每種想用的情緒至少 5 分鐘。
- [ ] 分散在很多天、很多種直播；一場不超過總量 10%。
- [ ] 開場和結尾的固定台詞，同一句不超過 5 次；已經登記成口頭禪並有原音。
- [ ] 日文、英文各至少 2–3 小時。
- [ ] 總共 5–10 小時乾淨語音（交給 AI 篩的話請它交 12–14 小時）。
