# 2. 聲音與同意

平台裡每個要訓練的人都是一個「聲音」。**沒有完整同意紀錄的聲音不能建立資料集、不能訓練、也不能做免訓練合成**——這是平台的硬性規定，不是提醒。

## 三種聲音

| 種類 | 什麼時候用 | 同意紀錄需要 |
|---|---|---|
| 我自己 | 你自己的聲音 | 你的簽名（打字）、日期、勾選用途 |
| 其他人 | 朋友、家人、合作的配音員 | 對方簽名、日期、用途，**再加上**簽名同意書的掃描檔／照片，或註明紙本放在哪裡 |
| 原創設計聲音 | 你設計的角色聲音，由某位有同意的人錄製 | 錄音者的同意 |

不可以用的聲音：藝人、主播、VTuber、名人、遊戲或動畫角色的原聲，以及任何沒有親自同意的人。即使你手上有大量他們的影片也一樣。

## 建立聲音

1. **聲音與同意 → 新增聲音**，填名稱、種類、會說的語言。
2. 在右邊的詳細頁填 **同意紀錄**：
   - 簽名的人、日期、和你的關係；
   - 同意的用途：**訓練**、**合成**（兩個都要勾，才能訓練）、是否只限個人使用；
   - 「其他人」要上傳同意書（PDF、照片都可以）或寫明紙本保管位置；
   - 最後勾選確認。
3. 看到綠色盾牌就完成了。

### 同意書範本（給「其他人」）

> 本人＿＿＿＿同意＿＿＿＿使用我於＿＿年＿＿月至＿＿年＿＿月間的錄音，訓練模仿我聲音的語音合成模型，並用該模型產生語音。
> 用途限於：□個人創作 □非商業公開發表 □商業用途（請說明）＿＿＿＿
> 我可以隨時以書面撤回同意；撤回後，使用者應刪除以我的錄音訓練的模型與資料。
> 簽名：＿＿＿＿　日期：＿＿＿＿

## 聲紋登錄（強烈建議）

聲紋是 1–5 段（建議 3 段以上）「只有這個人在說話」的乾淨錄音（每段 5–30 秒）。平台用它在多人錄音裡認出這個人，也用它來評分訓練好的模型像不像本人。

- 在聲音詳細頁按「加入聲紋」上傳。
- 不同日子、不同情緒的錄音各一段最好。

## 口頭禪

聲音詳細頁下方的 **口頭禪**：登記這個人最有特色的幾句話（例如「えっとね」「やっほー」「Let's gooo」）。

1. 填 **寫法**（你希望統一用的寫法），**其他寫法** 填語音辨識常寫成的樣子（例如「ヤッホー、やっほ〜」），選語言，按「登記」。
2. 平台會：
   - **匯入時**提示語音辨識用你的寫法（匯入時語言要選日文或英文才會提示）；
   - 顯示 **訓練資料裡出現幾段**。少於 20 段時，模型可能學不到它的念法，用原音比較保險；
   - 已經匯入的資料裡有其他寫法時，按 **統一寫法** 一次改好（兩個辨識結果都會改，分數會重算）。
3. **加入原音**：每個口頭禪收 2–5 段本人的錄音，最好是不同語氣（平常、興奮、小聲……），並標上情緒。
   - **從匯入的片段剪**：搜尋含有口頭禪的片段，平台會先估一個範圍，按「聽選取範圍」調整到剛好只有口頭禪（前後的靜音會自動去掉）。
   - **上傳檔案**：自己剪好的 0.2–10 秒錄音。
4. **模型自己念得像不像？**：選一個模型按「檢查念法」，平台用模型單獨念每個口頭禪（不換原音），並和原音比較：念對了沒、聲紋像不像、長度和本人差多少（念得太快或太慢，就是沒學到那個節奏）。

合成時怎麼使用原音，見〈文字轉語音〉的「口頭禪用原音」。

## 聲音標籤：吸氣、嘆氣、喘氣…

聲音詳細頁「口頭禪」下面的 **聲音標籤** 卡片。模型學的是「說話」：吸氣、嘆氣、喘氣、嬌喘、呻吟這種**沒有字的聲音**，語音辨識寫不出文字，所以幾乎沒有進到訓練資料，模型也很難自己發出來。聲音標籤的做法是：**用你本人錄到的那個聲音**，在文字裡寫 `[喘氣]` 的地方播出來。

1. **登記標籤**：按 `[吸氣]` `[大口吸氣]` `[嘆氣]` `[喘氣]` `[嬌喘]` `[輕笑]` 這些按鈕，或在「其他」打名字（例如 `呻吟`、`咳嗽`）按「登記」。用[〈標籤一覽〉](14-tags)裡的名字時，文字裡寫它的任何一種寫法都會播（登記 `[喘氣]`，寫 `[panting]`、`[はぁはぁ]` 也會播）；自己取的名字，文字裡要寫一模一樣（全形括號 `［］` 也可以）。
2. **找你的錄音裡有沒有這些聲音**：按「**掃描我的錄音**」。平台會看這個聲音匯入過的**所有**錄音，包括被排除的片段和片段之間的空檔（單獨的一聲嘆氣通常就在那裡），列出候選：
   | 候選 | 怎麼找到的 |
   |---|---|
   | 呼吸聲 | 沒有聲帶振動、像氣流的聲音，0.25–2.5 秒，比說話小聲。會標「在句子前（多半是吸氣）」「在句子後（多半是吐氣、嘆氣）」或「單獨」 |
   | 喘氣 | 連續 3 口以上短促的氣息，中間幾乎沒有說話 |
   | 逐字稿裡的聲音（藍色）：嘆氣、喘氣、倒抽一口氣、笑聲、哭聲、咳嗽、清喉嚨、打噴嚏、吸鼻子、打哈欠、哼歌、嘖、哼・嗤笑、尖叫、呻吟、吞口水、打嗝 | 日文：「はぁ」「はぁはぁ」「ふぅ」「あはは」「ぐすっ」「ゴホッ」「くしゅん」「ふぁ〜」「ちっ」「きゃー」「ごくり」…<br>英文：語音辨識常寫成 `(laughs)` `*sighs*` `[Laughter]` `(breathing heavily)` `(clears throat)`，或 `haha` `ugh` `phew` `achoo` `tsk` `pfft` `aaah`…<br>中文：「唉」「哈哈」「咳咳」「哈啾」「嘖」… |
   | 沒有字的聲音 | 片段有聲音、但逐字稿是空的或只有「んっ」「あっ」「嗯」「啊」「mm」：呻吟、哼聲、笑聲、嬌喘多半在這裡 |
3. **確認**：每個候選按播放聽（會多播前後各 0.4 秒）。
   - 是你要的 → 按「**收下…**」，選要放進哪個標籤（或開新標籤），用滑桿調到只剩那個聲音（不要包含說話的字），可以標情緒，按「收下」。
   - 不是 → 按「**不是**」。重新掃描時，收下和「不是」的都不會再出現；按錯了可以在右上角切到「不是」再「復原」。
4. 每個標籤收 **2–5 段**，最好是不同情緒（例如累的喘氣、害怕的喘氣），合成時會挑和那一句情緒相同的那段。
5. 錄音裡找不到的話，也可以自己錄：按標籤旁的「**加入原音**」→「上傳檔案」，上傳一段只有那個聲音的 0.2–10 秒錄音。

**要知道的事**

- 偵測靠的是音量、有沒有聲帶振動、聲音集中在哪個頻率，所以是**候選**，一定要聽過再收。背景有音樂或雜音的地方分不出呼吸聲，只會從逐字稿找。
- 音量：從錄音收下的聲音，會記住它原本和你說話聲的音量比例，合成時照這個比例放（呼吸聲還是呼吸聲的大小）；自己上傳的檔案照原本音量，只有比旁邊說話大聲時才會調小。
- 還沒有原音的標籤只當語氣提示（例如 `[喘氣]` → 「breathless, panting」），見〈文字轉語音〉的標籤表。

## 撤回同意

把聲音刪除，或清掉同意紀錄：之後就不能再建資料集或訓練。已經訓練的模型請在「模型」頁一併刪除（平台不會自動刪除，因為那是你的決定）。
