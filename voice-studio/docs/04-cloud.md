# 4. 雲端訓練（RunPod）

訓練一個 20 億參數的語音模型需要 24–80 GB 顯示記憶體，所以在雲端租 GPU，按小時計費，跑完自動關機。平台用的是 **RunPod**：按秒計費、價格透明、有可以長期保存檔案的「網路磁碟」，而且整個流程都能用 API 自動化。

## 一次性設定（約 10 分鐘）

### 1. 註冊與儲值
到 runpod.io 註冊，Billing 儲值。第一次建議 $10–25。

### 2. 建立網路磁碟（Network Volume）
Storage → **New Network Volume**：

- **資料中心**：選有 S3 API 的（平台設定頁的下拉選單就是這份清單，例如 `EU-RO-1`、`US-KS-2`、`EUR-IS-1`）。同一個資料中心要有你想用的 GPU，選前可以在 RunPod 的 GPU 列表看一下。
- **大小**：LoRA 用 150 GB 夠；要做完整微調選 300 GB。費用約每 GB 每月 $0.07（150 GB ≈ $10.5/月）。不用時可以刪掉磁碟停止計費（下次訓練會重新安裝環境）。

網路磁碟用來放：訓練環境（只裝一次）、基礎模型快取、每次的資料與結果。

### 3. API 金鑰
Settings → **API Keys** → Create API Key：權限選 **All**（或至少 Pods 和 Network Volumes 的讀寫）。

### 4. S3 金鑰
Settings → **S3 API Keys** → Create：會給你一組 **Access key**（`user_` 開頭）和 **Secret**（`rps_` 開頭）。Secret 只會顯示一次，請直接貼到平台。

### 5. 填進 Voice Studio
**設定 → 雲端 GPU**：

1. 貼上 API 金鑰、S3 Access key、S3 Secret，各按「儲存」。
2. 按 **測試連線**，在清單裡點你的網路磁碟 → ID 和資料中心會自動填好。
3. 設定「單次訓練最長時數」（預設 12 小時）。

金鑰存在 Windows 認證管理員，不會出現在任何檔案、紀錄或畫面上。

## 開始訓練

**雲端訓練** 頁：

1. **訓練資料集**：選一個（在「檢查資料」建立）。
2. **引擎**：
   - **VoxCPM2（推薦）**：最像本人，有「完整複製」模式保留口音與節奏。
   - **Qwen3-TTS 1.7B**：念錯字最少，當作對照。
   - 測試引擎：不會產生真的聲音，用來確認 RunPod 設定都對（幾分鐘、幾毛錢）。
3. **訓練方式**：
   - VoxCPM2 **LoRA**（建議先跑）：0.3 小時以上的資料都可以。
   - VoxCPM2 **完整微調**：5 小時以上的資料再考慮，先有 LoRA 當對照。
4. **GPU**：顯示的是即時價格和庫存。平台**只租你選的那一張**，不會自動換成更貴的卡；沒貨時會告訴你，換一張再按一次。
5. 看一下 **預估時間與費用**、實際會跑幾個 epoch，勾選確認，按「開始雲端訓練」。預估用的參數就是送到雲端的參數，兩者一定一致。

### 第一次建議的順序
1. 先用 **測試引擎** 跑一次（確認金鑰、磁碟都對，幾分鐘、幾毛錢）。
2. 第一次跑真的引擎前，到設定把「單次訓練最長時數」暫時調到 **1 小時**，用一小份資料跑 **VoxCPM2 LoRA**：確認安裝、訓練、試念、下載都順利，再把上限調回來跑完整的資料。
3. 資料整理到 5–10 小時後，同一個資料集分別跑 VoxCPM2 LoRA、VoxCPM2 完整微調、Qwen3-TTS，在「模型」頁比較。

## 訓練時發生什麼事

| 階段 | 時間 | 說明 |
|---|---|---|
| 上傳資料 | 視網速 | 打包已核可的片段上傳到網路磁碟 |
| 啟動 GPU | 1–3 分 | 開一台雲端機器 |
| 安裝環境 | 第一次約 10 分，之後幾秒 | 安裝固定版本的訓練程式，存在網路磁碟上 |
| 下載基礎模型 | 第一次約 3–5 分 | 也存在網路磁碟上 |
| 訓練 | 視資料量 | 用官方的訓練設定；途中存好幾個檢查點 |
| 打包模型 | 幾分鐘 | 訓練一結束就先把權重存到網路磁碟（model.tar），之後就算出錯也不會遺失 |
| 試念樣本 | 5–15 分 | 每個檢查點（和訓練前的模型）念同一批沒看過的句子（samples.tar） |
| 關機 | 1 分 | 機器自己刪除自己 |
| 下載、評分 | 視網速 | 下載到 `data\models`，自動評分各檢查點 |

進度、loss（越低代表越貼近訓練資料，但太低可能是死背）和預估剩餘時間會即時更新。按「紀錄」可以看雲端機器的完整輸出。

### 多重保險，不會忘了關機
1. 雲端機器做完、失敗、被取消或程式意外結束時，都會刪除自己；刪除失敗會一直重試，試到第 3 次會先「停機」（停止 GPU 計費）。
2. 機器上有獨立的計時器：到「最長時數」會先停掉訓練程式，再刪除機器。
3. 平台這邊結束時也會再刪一次；刪不掉會在訓練紀錄上標紅字，下次開啟時自動再試。
4. 每次開啟 Voice Studio、以及開著「雲端訓練」頁時，平台會檢查你的 RunPod 帳號上有沒有 Voice Studio 開的、但已經沒有在用的機器，自動關掉或提醒你刪除。
5. 送出開機請求時如果網路斷掉，平台會用機器名稱到 RunPod 找回那台機器，不會留下「不知道存在」的機器。

這些都在你的電腦開著的時候最可靠。保險起見，訓練中偶爾到 runpod.io → Pods 看一下也好。

### 關掉 Voice Studio 也沒關係
雲端機器會繼續訓練，時間到也一定會關機。下次開啟時平台會自動重新連上，下載結果。

### 試念失敗也不會遺失模型
權重在訓練結束時就先存好了。萬一試念階段出錯，模型照樣下載，只是模型頁沒有檢查點比較。

## 大概要花多少錢？

依 2026-09-27 RunPod Secure Cloud 價格（網路磁碟只能搭配 Secure Cloud）：

| GPU | 每小時 | 適合 |
|---|---|---|
| RTX 4090 24GB | $0.74 | 測試引擎 |
| RTX 6000 Ada 48GB | $0.84 | VoxCPM2 LoRA |
| L40S 48GB | $1.09 | VoxCPM2 LoRA（預設） |
| A100 80GB | $1.59 | VoxCPM2 完整微調、Qwen3-TTS（預設） |
| H100 80GB | $2.89–3.49 | 資料很多、想快一點時 |

粗估（還沒有人公開過這個組合的實測速度，第一次的估計可能差到 2 倍；平台跑完一次後會用實測速度校正）：

| 已核可語音 | VoxCPM2 LoRA（L40S，2 epoch） | VoxCPM2 完整微調（A100，1.5 epoch） |
|---|---|---|
| 1 小時 | 約 0.8 小時 ≈ $0.9 | — |
| 10 小時 | 約 1.3 小時 ≈ $1.5 | 約 1.3 小時 ≈ $2 |
| 50 小時 | 約 5 小時 ≈ $5.5 | 約 5 小時 ≈ $7.5 |

第一次使用某個引擎時，安裝環境和下載模型會多 15 分鐘左右。

再加上網路磁碟每月 $10–21。

## 出錯時

| 狀況 | 原因與處理 |
|---|---|
| 測試連線：401 / 403 | API 金鑰貼錯或權限不足，重新建立一把 All 權限的。 |
| 上傳失敗、SignatureDoesNotMatch | S3 金鑰或資料中心不對。在設定頁「測試連線」後點選磁碟，讓它自動填資料中心。 |
| 「沒有租到 GPU」 | 那個資料中心目前沒有你選的卡。換一張 GPU，或晚點再試。 |
| 「not enough disk」 | 雲端機器的磁碟不夠放檢查點。改用 LoRA，或回報給 Claude 調整磁碟大小。 |
| 訓練紀錄上有紅字「雲端機器可能還在計費」 | 到 runpod.io → Pods 手動刪除那台機器；平台下次開啟也會再試。 |
| 安裝環境失敗 | 看紀錄最後幾十行；多半是網路暫時問題，按「重試」。 |
| 訓練失敗：CUDA out of memory | 換更大記憶體的 GPU（LoRA 用 48 GB、完整微調用 80 GB）。 |
| 超過最長時數 | 到設定調高上限後重試。 |

遇到看不懂的錯誤，把「紀錄」裡最後 50 行複製給 Claude 或 GPT 問。紀錄裡不含任何金鑰。
