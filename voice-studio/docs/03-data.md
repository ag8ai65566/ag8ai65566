# 3. 匯入錄音與檢查資料

## 要準備多少錄音？

| 已核可的乾淨語音 | 可以做到 |
|---|---|
| 5–30 分鐘 | 免訓練或 LoRA：音色有點像，口音、習慣抓得不多 |
| 1 小時 | 第一次 LoRA 試跑，確認整個流程 |
| 5–10 小時 | 認真的比較：VoxCPM2 LoRA、完整微調、Qwen3-TTS |
| 10–20 小時 | 實用目標：涵蓋你要的語言和各種語氣 |
| 20–50 小時以上 | 只在補足缺少的語氣、發音、場合時才有幫助；越多不一定越好 |

**日文和英文都要說**：如果你希望模型用你的口音說日文，就要有你說日文的錄音。模型會說英文，不代表它學到了你說英文的方式。

錄音品質比數量重要：一個人說話、沒有背景音樂、沒有回音、不爆音。平常說話的錄音（直播、聊天、Podcast）比照稿念的錄音更能學到說話習慣。

## 匯入

**匯入錄音** 頁：

1. **這些錄音裡主要是誰？**
   - 只有一個人：選那個聲音。跟他不像的片段會被標成「不確定是誰」。
   - 多人（例如兩人對談）：選「自動分辨」。處理完後按「N 段待指定」，聽每一群的樣本，指定給對的聲音；其他人選「不是任何人」。
2. **語言**：不確定就選自動，日英混雜也可以。
3. **去除背景音樂**：只有在有音樂或遊戲音效時勾選。
4. 把檔案拖進去；或在「匯入資料夾」貼上資料夾路徑（大量檔案用這個，不會複製檔案）。

處理流程（自動）：解碼成 48 kHz → 偵測有人說話的地方 → 切成 2–15 秒的句子（在停頓處切）→ 認出是誰 → 用 Whisper large-v3 和 large-v3-turbo 各轉一次文字並比對 → 打分數。

一小時的錄音在 RTX 4070 等級的顯示卡上大約要 5–10 分鐘。

## 檢查資料

這一步決定模型的品質。**檢查資料** 頁：

- 上方切換聲音、狀態（待檢查／已核可／已排除）、排序，點警告標籤可以只看有某種問題的片段。
- 每一行：▶ 播放、文字（直接改，離開欄位就會儲存）、分數、長度、像本人的程度、警告。
- 兩個辨識模型結果不同時，會顯示「另一個辨識」，按「用這個」可以直接換。
- 右邊的 ✓ 核可、✗ 排除。

### 鍵盤

| 鍵 | 動作 |
|---|---|
| J / K | 下一個 / 上一個 |
| 空白鍵 | 播放 / 暫停 |
| A | 核可（跳到下一個） |
| R | 排除（跳到下一個） |

### 有效率的檢查方式

1. 排序選「分數高→低」，警告選「不限」，狀態「待檢查」。
2. 高分（綠色、沒有警告）的片段抽聽幾個，沒問題就按「核可全部符合的」——可以先把篩選條件縮到分數高的部分。
3. 再把排序改成「分數低→高」，一個一個處理有警告的。
4. 不確定就排除。

### 文字要怎麼寫？

- **照實寫**：「えっと」「あの」「um」「like」、說錯重講、笑聲裡的字都照寫。模型是從這些學到說話習慣的。
- 日文用正常的漢字假名混寫，不要整句改成羅馬拼音。
- 數字、日期、英文縮寫，寫成實際念出來的樣子（例如念「にじゅうよじ」就寫「二十四時」或「にじゅうよじ」，不要寫「24時」以外的讀法）。

## 建立訓練資料集

檢查頁右邊的 **訓練資料集**：

- 設定最低分數（預設 0.5），按「建立新的資料集」。
- 資料集是當下的快照：之後再修改片段，不會影響已經建立的資料集，所以每次訓練用的資料都有紀錄。
- 平台會自動留下一小部分（以整段錄音為單位）不拿來訓練，用來檢查模型是不是真的學會，而不是背答案。
- 按「訓練」就會帶著這個資料集到雲端訓練頁。
