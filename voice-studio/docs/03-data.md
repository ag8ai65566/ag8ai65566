# 3. 匯入錄音與檢查資料

## 要準備多少錄音？

以**每個人**、**檢查完核可後**的時數計算（原始影音去掉別人說話、笑聲、音樂、雜音後會少一截）：

| 已核可的乾淨語音 | 可以做到 |
|---|---|
| 5–30 分鐘 | 免訓練或 LoRA：音色有點像，口音、習慣抓得不多 |
| 1 小時 | 第一次 LoRA 試跑，確認整個流程。效果常常和免訓練差不多 |
| **5–10 小時** | **建議目標**：微調開始明顯學到語速、節奏、句尾習慣；可以比較 VoxCPM2 LoRA、完整微調、Qwen3-TTS |
| 10–20 小時 | 只有在多出來的部分帶來新的語氣、場合或語言時才有幫助 |
| 20 小時以上 | 幾乎沒有幫助；錄音很單調時（例如全是同一種念稿）甚至可能變差 |

**日文和英文都要說**：如果你希望模型用你的口音說日文，就要有你說日文的錄音，每種語言建議至少 2 小時。模型會說英文，不代表它學到了你說英文的方式。

**多樣比時數重要**：平靜聊天、興奮、小聲、不高興、念稿、不同場合和麥克風都要有一些。同一種場合、同一種情緒的錄音再多，模型也只會那一種，還會把那批錄音的雜音和回音一起學走。

### 公開案例（2026 年）

| 案例 | 資料 | 訓練 | 結果 |
|---|---|---|---|
| Qwen3-TTS 微調有聲書旁白（GitHub 公開專案） | 8.5 小時 | A100 約 13 分鐘、約 4 美元 | 幾乎沒念錯；語速和本人幾乎一樣；長段落比免訓練穩定 |
| Baseten 微調 Qwen3-TTS | 1.5 小時 | H100 約 1 小時 | 相似度和音質沒有明顯贏過免訓練 |
| VoxCPM2 LoRA 學高棉語、韓語（論文） | 3 小時、20 小時 | H200 每組 2.6 小時 | 高棉語評分 3.85→4.23；韓語 20 小時卻沒有顯著進步 |
| LoRA 與資料多樣性（論文，6 個人） | 每人 3.5–18.5 小時 | — | 起伏大的 3.5–3.9 小時進步；很平的 17–18 小時有聲書反而變差 |
| ElevenLabs、Azure 的商用建議 | 30 分鐘–3 小時 | — | 兩家都說 2–3 小時左右就是最佳 |

所以建議分三次跑：1 小時（確認流程）→ 5 小時 → 10 小時，在「模型」頁比較。10 小時聽不出比 5 小時好，就停在 5 小時，之後只補模型還不會的語氣。

## 匯入

**匯入錄音** 頁：

1. **這些錄音裡主要是誰？**
   - 只有一個人：選那個聲音。跟這個人不像的片段會被標成「不確定是誰」。
   - 多人（例如兩人對談）：選「自動分辨」。處理完後按「N 段待指定」，聽每一群的樣本，指定給對的聲音；其他人選「不是任何人」。
2. **語言**：知道是日文或英文就直接選，平台會提示辨識模型「照實寫出えーと、あの、um、uh 這類口頭禪」，保留說話習慣。日英混雜或不確定才選自動（這時口頭禪比較容易被省略，檢查時要多留意）。
3. **情緒／風格**（選填）：整個檔案都是同一種情緒時才選，例如專門錄的一段生氣台詞。一般直播或影片請留空，之後在檢查頁逐句標。已經匯入的檔案，也可以在下方清單改整個檔案的情緒（你逐句改過的不會被覆蓋）。
4. **去除背景音樂**：只有在有音樂或遊戲音效時勾選。
5. 把檔案拖進去；或在「匯入資料夾」貼上資料夾路徑（大量檔案用這個，不會複製檔案）。

處理流程（自動）：解碼成 48 kHz → 偵測有人說話的地方 → 切成 2–15 秒的句子（在停頓處切）→ 認出是誰 → 用 Whisper large-v3 和 large-v3-turbo 各轉一次文字並比對 → 打分數。

一小時的錄音在 RTX 3080／4070 等級的顯示卡上大約要 5–10 分鐘。

## 檢查資料

這一步決定模型的品質。**檢查資料** 頁：

- 上方切換聲音、狀態（待檢查／已核可／已排除）、排序，點警告標籤可以只看有某種問題的片段。
- 每一行：▶ 播放、文字（直接改，離開欄位就會儲存）、分數、長度、像本人的程度、警告。
- 兩個辨識模型結果不同時，會顯示「另一個辨識」，按「用這個」可以直接換。
- 右邊的 ✓ 核可、✗ 排除。

### 鍵盤

| 鍵 | 動作 |
|---|---|
| J / K | 下一個 / 上一個 |
| 空白鍵 | 播放 / 暫停 |
| A | 核可（跳到下一個） |
| R | 排除（跳到下一個） |

### 標情緒

每一行的「情緒…」可以標上平靜、開心、興奮、生氣、難過、小聲、笑著說、驚訝、害怕、悄悄話、撒嬌、念稿／旁白。鍵盤更快：選到那一行按 **1–9**（1 平靜、2 開心、3 興奮、4 生氣、5 難過、6 小聲、7 笑著說、8 驚訝、9 害怕），**0** 清除。上方可以依情緒篩選，「全部符合的標成…」可以一次標一整批。

標情緒**不會讓模型學得更好或更差**：兩個引擎的訓練格式都沒有情緒欄位，模型是直接從聲音學會這個人生氣時怎麼說話。標情緒的用處是：

- 右邊「訓練資料集」會顯示**各情緒有幾分鐘**，不到 5 分鐘（約 50 段）的會提醒你；
- 建立資料集時，平台會為**每種標過的情緒各挑一段參考片段**，訓練好的模型會帶著它們；
- 合成時選了情緒（或風格提示、劇本的 [angry] 標籤），平台會挑**那種情緒的參考片段和口頭禪原音**，這是控制語氣最可靠的方法。

不用每一段都標。常用的語氣各標幾十段就夠用了。

### 自動審核（錄音很多時用這個）

幾十小時的錄音切出來會有上萬段，一段一段聽不實際。右邊的 **自動審核** 會在你的電腦上幫你先分好：

| 結果 | 條件 | 你要做什麼 |
|---|---|---|
| 自動核可 | 兩個辨識模型的文字幾乎一樣、整段都是本人（每 2 秒檢查一次聲紋，中途換人會被抓到）、雜音少、沒爆音、語速合理 | 只聽「抽查」的那一小部分 |
| 自動排除 | 明顯是別人、雜音或音樂太多、兩個辨識結果差很多、字數和長度對不上（多半是笑聲或沒說話） | 不用管；想看原因就切到「已排除」 |
| 需要你聽 | 介於兩者之間 | 一段一段聽，按 A 或 R |

步驟：

1. 先在 **聲音與同意** 頁登錄這個人的聲紋（1–5 段只有這個人在說話的乾淨錄音，見〈聲音與同意〉）。沒有聲紋時，平台會改用你已核可的片段或最清楚的片段當基準；連這些都不夠就會請你先手動核可 5 段。
2. 選 **平衡**（一般情況）或 **嚴格**（資料很多、寧可少一點也要乾淨），按「自動審核」。一萬段大約幾十分鐘，進度在右上角。
3. 按「① 需要你聽」：只列出拿不準的片段，每段下面會寫原因（例如「中途可能換人或有別的聲音」）。
4. 按「② 抽查自動核可的」：隨機抽出的已核可片段（至少 10 段、最多 100 段）。沒問題按 **A**，有問題按 **R**。
5. 抽查時你排除的比例超過一成，平台會建議你按「復原自動審核」，改用「嚴格」再跑一次。

注意：

- 你自己改過文字、或已經核可／排除的片段，自動審核不會動。
- 「復原自動審核」只會把自動做的決定改回「待檢查」，你自己做的決定都保留。
- 自動審核看不出「文字照實寫了沒有」：兩個辨識模型可能一起把口頭禪省略掉。所以語言請直接選日文或英文（見上面的「匯入」），抽查時也順便看一下文字。

### 少量錄音時的檢查方式

1. 排序選「分數高→低」，警告選「不限」，狀態「待檢查」。
2. 高分（綠色、沒有警告）的片段抽聽幾個，沒問題就按「核可全部符合的」——可以先把篩選條件縮到分數高的部分。
3. 再把排序改成「分數低→高」，一個一個處理有警告的。
4. 不確定就排除。

### 文字要怎麼寫？

- **照實寫**：「えっと」「あの」「um」「like」、說錯重講、笑聲裡的字都照寫。模型是從這些學到說話習慣的。
- 日文用正常的漢字假名混寫，不要整句改成羅馬拼音。
- 數字、日期、英文縮寫，寫成實際念出來的樣子（例如念「にじゅうよじ」就寫「二十四時」或「にじゅうよじ」，不要寫「24時」以外的讀法）。

## 建立訓練資料集

檢查頁右邊的 **訓練資料集**：

- 設定最低分數（預設 0.5），按「建立新的資料集」。
- 資料集是當下的快照：之後再修改片段，不會影響已經建立的資料集，所以每次訓練用的資料都有紀錄。
- 平台會自動留下一小部分（以整段錄音為單位）不拿來訓練，用來檢查模型是不是真的學會，而不是背答案。
- 按「訓練」就會帶著這個資料集到雲端訓練頁。
