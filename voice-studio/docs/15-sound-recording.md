# 15. 錄聲音標籤的原音

聲音標籤（`[喘氣]`、`[嘆氣]`、`[笑聲]`……）放進你自己錄的聲音後，合成時會在標籤的位置播這段原音，前後是模型合成的聲音。原音要接得天衣無縫，最重要的是**和你的訓練素材聽起來是同一個人、同一個房間、同一支麥克風**。這一頁是錄音規格；上傳時平台會自動檢查，不合格的會標出來。

> 不想另外錄的話，也可以在聲音頁按「掃描我的錄音」，從已經匯入的直播裡找（見〈聲音與同意〉）。從錄音裡剪出來的原音，平台知道它和你說話聲的音量比例，接起來最自然。

## 一、規格一覽

| 項目 | 規格 | 為什麼 |
|---|---|---|
| 格式 | **WAV**（或 FLAC），48 kHz 或 44.1 kHz，24-bit（16-bit 也可以），單聲道 | MP3、AAC 會把呼吸聲的高頻細節壓掉，聽起來像水聲 |
| 器材 | 和訓練素材**同一支麥克風、同樣的距離、同一個房間** | 音色或空間感不一樣，接在合成聲音中間會一聽就出戲 |
| 距離 | 嘴巴離麥克風 15–25 公分；吸氣、喘氣、吹氣類稍微偏一點角度（約 30 度） | 太近或正對著，氣流會噴麥（「噗」聲） |
| 增益 | 用**平常說話**的增益：說一句話時峰值約 −12 到 −6 dBFS。錄各種聲音時**不要再調增益，也不要事後放大** | 呼吸聲本來就比說話小聲，平台照原本的大小放 |
| 峰值 | 最大不超過 −3 dBFS，**絕對不能爆音** | 爆音沒辦法修 |
| 背景 | 底噪 −60 dBFS 以下：關風扇、冷氣、窗戶，手機靜音，離電腦遠一點 | 呼吸聲很小聲，背景噪音會比它還明顯 |
| 處理 | **關掉**降噪、自動增益、噪音閘（OBS／Discord 的濾鏡、手機錄音的「語音增強」） | 噪音閘會把呼吸聲當噪音切掉；降噪會把氣音弄糊 |
| 房間 | 有窗簾、床、衣櫃的小房間；不要在浴室或空曠的房間 | 回音會讓原音和合成的聲音空間不一致 |
| 長度 | 去掉前後靜音後 **0.3–3 秒**；喘氣、大笑最多約 5 秒。前後各留 0.3 秒左右的安靜 | 前後的靜音平台會自動切掉；太長的聲音會打斷句子 |
| 內容 | **一個檔案只有一個聲音，不要有字**。嘆氣帶一點「はぁ」可以，接著說「疲れた」就不行 | 有字的話會和後面合成的字重複 |
| 數量 | 每個標籤 **3–5 段**，強弱和情緒都不同 | 合成時挑和那一句情緒相同的；同一句的不同版本會輪流用 |
| 檔名 | `情緒_序號.wav`，例如 `tired_01.wav`、`[害羞] 2.wav`、`開心_03.wav`；同一個聲音放同一個資料夾，例如 `sounds/喘氣/` | 上傳時勾「情緒照檔名」就會自動標好情緒 |

## 二、先錄哪些

不用全部錄。先錄**第一優先**，最常用，也最能讓合成聽起來像真人；其他看你寫的內容需要。

| 優先 | 聲音標籤 |
|---|---|
| 第一優先 | `[吸氣]`、`[大口吸氣]`、`[嘆氣]`、`[鬆一口氣]`、`[喘氣]`、`[輕笑]`、`[笑聲]` |
| 第二優先 | `[倒抽一口氣]`、`[吐氣]`、`[咯咯笑]`、`[偷笑]`、`[噴笑]`、`[大笑]`、`[乾笑]`、`[苦笑]`、`[冷笑]`、`[吸鼻子]`、`[抽泣]`、`[清喉嚨]`、`[咳嗽]`、`[打哈欠]`、`[思考的嗯]`、`[不屑地哼]`、`[嘖]` |
| 看需要 | `[嬌喘]`、`[哭聲]`、`[嗚嗚]`、`[笑到喘]`、`[狂笑]`、`[打噴嚏]`、`[哼歌]`、`[呻吟]`、`[低吟]`、`[悶哼]`、`[吞口水]`、`[打嗝]`、`[屏息]`、`[尖叫]`、`[驚叫]`、`[興奮尖叫]`、`[歡呼]`、`[吹口哨]`、`[親親聲]` |

標籤用〈標籤一覽〉裡的名字登記，文字裡寫它的任何一種寫法（中文、英文、日文）都會播你的原音：例如登記 `[喘氣]`，文字裡寫 `[panting]` 或 `[はぁはぁ]` 也會播。

## 三、每種聲音怎麼錄

表演的原則：**真的去做那件事**，不要「演」那個聲音。想著接下來要說的話、真的覺得好笑、真的累，錄出來最自然。

| 聲音 | 怎麼錄 | 長度 | 建議收的情緒 |
|---|---|---|---|
| 吸氣 | 想像下一秒要開口說話，用嘴吸一口氣，吸完停住，不要吐出來 | 0.3–0.8 秒 | 平靜、緊張、興奮 |
| 大口吸氣 | 準備大喊或要講一件大事之前的深吸氣 | 0.6–1.5 秒 | 興奮、緊張、認真 |
| 倒抽一口氣 | 被嚇到時短而急的吸氣，可以帶一點聲音（「ひっ」） | 0.2–0.6 秒 | 驚訝、害怕 |
| 嘆氣 | 肩膀放鬆，從胸口把氣吐出來；有聲（「はぁ…」）和純氣音各錄幾段 | 0.6–2 秒 | 疲倦、難過、不耐煩、無奈 |
| 鬆一口氣 | 短、往下沉的吐氣，像事情終於結束 | 0.4–1 秒 | 平靜、開心 |
| 吐氣 | 慢慢吐氣，沒有聲音 | 0.5–2 秒 | 平靜、疲倦 |
| 喘氣 | 原地跑 30 秒或爬樓梯後**真的喘**，錄連續 3–5 秒，節奏要有快慢變化 | 2–5 秒 | 疲倦、害怕、興奮 |
| 嬌喘 | 輕、柔、帶氣音的短喘，不要大聲 | 1–3 秒 | 害羞、撒嬌 |
| 屏息 | 吸一口氣後憋住，放開時輕輕吐出 | 0.5–1.5 秒 | 緊張 |
| 輕笑・咯咯笑・偷笑 | 想一件好笑的事，自然笑出來；偷笑要忍住、從鼻子漏出來 | 0.4–1.5 秒 | 開心、撒嬌、得意 |
| 笑聲・大笑・噴笑 | 看一段真的好笑的影片時錄；噴笑是忍不住「噗」一聲 | 1–4 秒 | 開心、興奮 |
| 乾笑・苦笑・冷笑 | 乾笑是尷尬的「哈哈…」；苦笑帶一點嘆氣；冷笑是從鼻子短短一聲 | 0.5–1.5 秒 | 害羞、諷刺、冷淡 |
| 吸鼻子・抽泣・哭聲 | 可以想著難過的事；吸鼻子短；抽泣是一抽一抽的吸氣 | 0.5–3 秒 | 難過、哭著說 |
| 清喉嚨・咳嗽 | 輕輕的就好，不要用力咳到喉嚨痛 | 0.3–1 秒 | 平靜、認真 |
| 打哈欠 | 真的想睡的時候錄（晚上或剛起床） | 1–3 秒 | 疲倦 |
| 思考的嗯 | 閉嘴的「嗯——」，音調平或微微往上 | 0.5–1.5 秒 | 平靜、疑惑 |
| 不屑地哼・嘖 | 從鼻子短短「哼」一聲；舌頭「嘖」一下 | 0.2–0.6 秒 | 不耐煩、得意 |
| 尖叫・驚叫 | 音量會很大：**先把增益調低一格**，錄完再調回來（這是唯一可以調增益的例外，避免爆音） | 0.5–2 秒 | 害怕、驚訝、興奮 |

**注意身體**：喘氣、大笑、尖叫這類錄幾次就休息，頭暈、喉嚨不舒服就停。不要連續過度換氣。

## 四、錄音流程

1. **準備**：喝水，休息一下；關掉降噪、自動增益、噪音閘。
2. **先錄 10 秒的房間安靜**，聽聽看有沒有風扇聲、電流聲（這段不用上傳）。
3. **對一下增益**：用平常的音量說一句話，峰值在 −12 到 −6 dBFS 之間。之後不要再動。
4. **每個聲音連錄 5–8 次**，中間停 2–3 秒，再用剪輯軟體（例如 Audacity：選取 →「匯出選取範圍」）剪成一段一個檔案，挑最自然的 3–5 段。不要加淡入淡出，平台會處理。
5. **照規則命名**：`情緒_序號.wav`，放在 `sounds/標籤名/`。
6. **上傳**：聲音頁 →「聲音標籤」→ 標籤旁的「加入原音」→「上傳檔案」，可以一次選好幾個，勾「情緒照檔名」。
7. **看檢查結果**：綠色＝符合規格；橘色＝已加入，但有建議（滑鼠移到原音旁的 ⚠ 可以看是哪裡不合）；紅色＝沒有加入（例如太長或太短）。
8. **試聽**：到文字轉語音寫一句，例如 `[大口吸氣] ねえ、聞いて。[嘆氣] もういいよ。`，聽接縫自不自然、音量突不突兀。不自然就換一段，或照檢查結果重錄。

## 五、上傳時的自動檢查

| 檢查 | 標準 | 不合格時怎麼辦 |
|---|---|---|
| 爆音 | 不能有被削平的波形（3 個取樣點以上就警告） | 增益調低重錄 |
| 太滿 | 峰值不超過 −1 dBFS（建議 −6 到 −3） | 增益調低一點 |
| 太小聲 | 峰值不低於 −35 dBFS | 用平常說話的增益錄，不要事後放大 |
| 背景噪音 | 安靜的地方不高於 −50 dBFS（建議 −60 以下） | 關掉噪音源，離電腦遠一點 |
| 音質 | 取樣率至少 32 kHz；11 kHz 以上要有聲音 | 錄 WAV，關掉手機的降噪或語音增強 |
| 壓縮格式 | MP3、AAC、Opus 會提醒 | 改錄 WAV |
| 長度 | 聲音標籤超過 5 秒會提醒；0.2–10 秒以外不收 | 剪短，一個檔案一個聲音 |

檢查只是提醒：除了長度，不合格的原音一樣會加入，你可以先試聽再決定要不要重錄。

## 六、常見問題

- **用手機錄可以嗎？** 可以，但要用能錄 WAV、可以關掉降噪的錄音 App，並放在和平常錄直播差不多的距離。手機和電腦麥克風的音色差很多，最好還是用同一支麥克風。
- **為什麼我的嘆氣播出來比說話大聲？** 上傳的原音照原本的音量播，只有比旁邊說話大聲時才會調小。如果你錄的時候把增益調高了，或事後放大過，就會偏大。用平常說話的增益重錄，或改從匯入的直播裡找（掃描我的錄音）。
- **嘆氣裡帶「はぁ」算有字嗎？** 不算，那是聲音。但「はぁ、疲れた」的「疲れた」是字，要剪掉。
- **一個標籤要錄幾種情緒？** 先錄平靜的 2 段，再補最常用的情緒各 1–2 段。情緒標錯也沒關係，之後可以在原音旁的選單改。
