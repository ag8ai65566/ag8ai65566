# 畫師風格清單（52 位）

**圖片分頁 → 🎤 角色包**，就在常用動作那排下面。點畫師名字加進提詞，再點一下拿掉。

⭐ = 你上傳的那份法典裡用過的畫師（共 20 位）。

---

## 先講三件會讓畫師 tag 白打的事

### 1. 你寫的名字，常常不是 danbooru 的 tag

這不是理論問題，你的法典裡就有兩個大的：

| 法典寫的 | danbooru 上 | 真正的 tag |
| --- | --- | --- |
| `artist:hiten`（**37 條**用到） | 0 張 | **`hiten (hitenkei)`**（921 張） |
| `aritst:deadflow`（**32 條**用到） | 0 張 | **`bee (deadflow)`**（1,321 張） |

也就是說法典裡用最多的兩個畫師，**寫出來的字誰也不是**。
（`aritst` 那個拼字錯誤動作庫已經自動修掉了，但名字本身還是要換。）

別名也一樣會踩到：`misu kasumi` 會被 danbooru 導向 `taromarun`，
別名本身在訓練標註裡不會出現。

搜尋框打錯的名字也會給你答案 —— 打 `hiten` 或 `deadflow` 都找得到正確的那位。

### 2. 前綴是**跟著底模走**的，而且有一支底模根本不吃

| 底模 | 寫法 | 說明 |
| --- | --- | --- |
| **NoobAI-XL** | `artist:wlop` | 它自己的模型卡就是這樣寫的 |
| **Illustrious XL** | `by wlop` | 這一支的慣例 |
| **Pony V6** | ❌ **沒有用** | 訓練時把畫師名字**整個從標註裡拿掉**了 |
| Juggernaut / SDXL 官方 | ❌ 沒有用 | 從來沒學過 danbooru 畫師標籤 |

介面會**自動用對的前綴**，切到 Pony 或寫實底模時會直接告訴你「這支不吃」，
旁邊一顆按鈕可以換成 NoobAI。

### 3. 「很有名」跟「模型認得」是兩回事

模型認不認得，看的是 **danbooru 上有多少張他的圖**，因為那才是微調真的看過的東西。
所以每一位後面都標了張數：

- **1,500 張以上** = 很穩，權重 1.0 就吃得到
- 500～1,500 = 一般
- **500 張以下** = 比較弱，可能要加權到 1.2 才明顯

WLOP 全世界都認識，但 danbooru 上只有 400 張 —— 所以他在這幾支底模裡其實**沒有想像中強**。

## 怎麼用

- **一次只掛一到兩位。** 掛三位以上會互相打架，出來變成四不像。
- 畫師放在**角色後面、動作前面**（法典自己的建議，動作庫也是照這個順序組的）。
- 上面有**畫師權重滑桿**（0.5～1.6），加進去時就帶著權重。
  加完之後也可以用 `Ctrl+↑` 微調。
- 每一位後面那串 **「特徵」是從 danbooru 統計出來的** —— 不是我瞎寫的印象。
  算法是「這個 tag 在他作品裡的出現率 ÷ 全站平均出現率」，取最突出的幾個。
  所以 `bkub` 會列出網點和四格、`wlop` 會列出紅唇和寫實。**風格描述可以拿那串來對照。**

## 我驗過什麼

| 驗過 | 結果 |
| --- | --- |
| 每個 tag 都是 danbooru 的**畫師分類**（category 1）且有圖 | 逐一查 API |
| 兩個法典寫錯的名字 | `hiten` → `hiten (hitenkei)`、`deadflow` → `bee (deadflow)`，兩個原字串都是 0 張 |
| 別名 | `misu kasumi` → `taromarun`、`sho (sho lwlw)` → `todoroki masaru` |
| 「特徵」那串 | 用 danbooru 的 related_tag API 算 lift（出現率 ÷ 全站基準），不是憑印象 |
| 三支底模各自送出什麼前綴 | Chromium 實機切換驗證：`artist:wlop` / `by wlop` / Pony 顯示警告 |
| 加權、移除、清空、搜尋、分類篩選 | 實機驗證 |
| 手機寬度 375px | 不溢出 |

**沒驗過的**：風格描述準不準。那是我根據統計特徵加上自己的認識寫的，
**沒有實際生成過任何一張圖**（這容器沒有 GPU）。覺得哪個描述不對就跟我說，我改。
