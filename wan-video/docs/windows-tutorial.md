# Windows 逐步教學：把圖片變成短動畫

寫給沒用過命令列的人。順利的話**完全不用打指令**，雙擊兩個檔案就好。

第一次要花的時間：裝東西 15 分鐘，下載模型 1～3 小時（看網速，可以放著去睡）。
**做完之後，以後每次只要雙擊一個檔案。**

---

## 0. 先確認你的電腦跑得動

這套東西一定要 **NVIDIA 顯卡**。AMD、Intel、筆電內顯都跑不動 —— 不是慢，是不能跑。

**怎麼看**：按 `Ctrl + Shift + Esc` 打開工作管理員 →「**效能**」分頁 → 看左邊那排。
會有 `GPU 0`（可能還有 `GPU 1`），點下去，右上角會寫顯卡型號。

- 寫 **NVIDIA GeForce RTX / GTX ⋯** → 可以,繼續
- 只有 **Intel UHD / Iris** 或 **AMD Radeon** → 這台不行,不用再往下做了

同一個畫面右下角有「**專用 GPU 記憶體**」,那個數字就是顯存。記一下:

| 顯存 | 情況 |
| --- | --- |
| 24GB 以上 | 最好,用最高畫質的模型 |
| 12～16GB | 沒問題,腳本會自動挑一個順順跑的 |
| 10～11GB | 可以,會自動用 HunyuanVideo（最省的那個） |
| 8GB 以下 | 能跑,但要加參數而且很慢,一支片十幾分鐘 |

> **重要:顯存不夠不等於不能用大模型。** 腳本只是挑一個「順順跑」的當起點。
> 你想用更大的模型隨時可以在網頁上裝 —— 顯存不夠時 ComfyUI 會用系統記憶體頂上,
> 一樣跑得出來,只是慢。網頁的「模型」分頁會照你的實際顯卡告訴你差多少、
> 大概慢幾倍、該加哪個參數。**這個 app 不會因為顯存小而擋你。**

**硬碟**要留 **60GB 以上**空間。程式本身約 10GB,一個模型 18～43GB。

> 不確定的話沒關係,腳本第一件事就是檢查,不行會直接告訴你並停下來,不會亂裝東西。

## 1. 裝 Python

1. 打開 <https://www.python.org/downloads/>
2. 找 **3.12** 版的 Windows 安裝檔下載
   （不要裝 3.14,太新;首頁那顆大按鈕可能是更新的版本,往下找 3.12）
3. 打開下載的檔案,**先不要按 Install**

   > **這一步最重要**:安裝視窗**最下面**有一個小方框
   > ☐ **Add python.exe to PATH**
   > **一定要勾**。沒勾的話後面會找不到 Python,要整個重裝一次。

4. 勾好之後按 **Install Now**,裝完按 Close

> **為什麼不能用微軟商店的 Python**:Windows 內建一個假的 `python` 捷徑,點了會打開
> 商店。腳本會認出這種情況並告訴你,但直接去官網裝就不會遇到。

## 2. 裝 Git

1. 打開 <https://git-scm.com/download/win>,下載 **64-bit Git for Windows Setup**
2. 打開檔案,**一路按 Next 到底,全部用預設值**,最後按 Install

> 這個是給腳本用的（它要去抓 ComfyUI）,你自己不會用到 Git。

## 3. 下載這個專案

1. 點這個連結,瀏覽器會直接下載一個 zip:

   <https://github.com/ag8ai65566/ag8ai65566/archive/refs/heads/claude/local-image-to-animation-ai-375zyw.zip>

2. 到「下載」資料夾找到那個 zip,**右鍵 → 解壓縮全部 → 解壓縮**
3. 解出來的資料夾名字很長,**改名成 `anim`**,然後**拖到桌面**
4. 點進 `anim`,裡面會看到一個 `wan-video` 資料夾 —— **我們要用的是這個**

> 把它放在桌面而不是「下載」,是因為下載資料夾容易被你自己清掉,而這裡面之後會有
> 幾十 GB 的模型。

---

## 4. 最簡單的做法:雙擊 `install.bat`

點進 `anim\wan-video`,裡面有一個 **`install.bat`** —— **雙擊它就好**,跳過下面第 5、6 步。

會跳出一個黑視窗開始跑。跑完會停在「Done. Next time, double-click start.bat」,
按任意鍵關掉。之後每次要用就**雙擊 `start.bat`**。

> 如果 Windows 跳出「已保護您的電腦」的藍色視窗:點「**其他資訊**」→「**仍要執行**」。
> 那是因為這個檔案是從網路下載的,不是因為有問題。

**雙擊沒反應、或黑視窗一閃就消失**的話,才需要走下面第 5 步的手動方式。

---

## 5. 手動方式（雙擊不行才用）

### 5a. 打開 PowerShell 並切到 `wan-video` 資料夾

按開始鍵,打 `powershell`,點「**Windows PowerShell**」（**不要**選有 `(x86)` 的）。

視窗打開的位置是家目錄,像 `PS C:\Users\Louis>`。**這不是我們要的位置**。
最不會錯的做法是用拖的,不用打路徑:

1. 在 PowerShell 裡打 `cd` 再加**一個空白**,畫面變成 `PS C:\Users\Louis> cd `
   —— **先不要按 Enter**
2. 打開檔案總管,找到桌面 `anim` 裡的 **`wan-video`** 資料夾（看到就好,不用點進去）
3. **把那個資料夾拖進 PowerShell 視窗放開**,完整路徑會自動填上
4. **這時**才按 Enter

**確認位置對不對**,貼這行按 Enter:

```powershell
Test-Path setup-windows.ps1
```

出現 `True` 才往下做。出現 `False` 表示位置不對 —— 回上面重切一次,注意要切到
`wan-video`,不是外面的 `anim`。

> 下面每一段指令都是:**複製 → 在視窗裡按滑鼠右鍵貼上 → 按 Enter**。
> PowerShell 貼上是按**右鍵**,不是 Ctrl+V。

### 5b. 貼上安裝指令

這步最久。貼這一行:

```powershell
powershell -ExecutionPolicy Bypass -File .\setup-windows.ps1
```

按 Enter 之後它會自己跑完全部:檢查顯卡 → 裝 PyTorch → 裝 ComfyUI → 下載模型。

### 你會看到什麼

一開始幾行是檢查結果,像這樣:

```
=== 檢查環境 ===
  OK  顯卡：NVIDIA GeForce RTX 4090（24GB 顯存）
  OK  先裝的模型：wan22-14b-fp8（之後可以在網頁上加裝其他的）
  OK  Python 3.12（C:\Python312\python.exe）
  OK  git
```

**看到這幾行 OK 就對了。** 它會照你的顯存自動挑模型,不用你決定。

之後會刷很多下載進度的字,最久的是模型（幾十 GB）。中間看到
`↓ wan2.2_i2v_high_noise_14B_fp8_scaled.safetensors（14.3GB）` 這種就是正在下載。

**這時候可以去做別的事或去睡**,不要關視窗。跑完最後會印:

```
=== 完成 ===
接下來每次要用，只要雙擊 start.bat
```

> **中途斷線或不小心關掉了怎麼辦**:重跑同一行指令就好,**已經下載的部分不會重來**,
> 它會從斷掉的地方接著下。

> **為什麼要加 `-ExecutionPolicy Bypass`**:PowerShell 預設禁止執行腳本檔,直接打
> `.\setup-windows.ps1` 會被擋掉。在指令前面加這段等於「這一次放行」,
> **不會改到你電腦的任何設定**,是最乾淨的做法。

## 6. 每次要用

**雙擊 `start.bat`**。或者用指令:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-windows.ps1
```

會跳出**兩個黑色視窗**（一個是 ComfyUI,一個是網頁程式）—— **兩個都不要關**,
關掉就停了。等個一兩分鐘,瀏覽器會自己打開:

```
http://127.0.0.1:8000
```

沒自動開的話,自己開瀏覽器打這個網址。

> 這個網址只有你這台電腦連得到,沒有對外開放。

**要結束的時候**:把那兩個黑色視窗關掉就好。

## 7. 生成第一支動畫

網頁上有五個分頁:**生成**、**素材庫**、**LoRA**、**模型**、**設定**。

在「**生成**」分頁:

1. **放圖** —— 把圖片拖進最上面那個虛線框。也可以點它選檔案,或直接 `Ctrl + V` 貼上
2. **打指令** —— 下面那個大框,寫**你要它怎麼動**。中文英文都可以
3. **選模型** —— 下拉選單,前面有 `✓` 的是已經裝好的
4. 按右下角 **生成**

下面「最近」會出現一張卡片,先是「排隊中」→「生成中」+ 進度條 → 「完成」。

> **第一次會特別久**（多等 1～3 分鐘）,因為要把模型讀進顯卡。第二支開始就快了。

### 指令要怎麼寫

重點是**寫動作和鏡頭**,不是寫畫面長什麼樣（畫面已經在你給的圖裡了）。

**好的例子**:

```
她慢慢轉頭看向鏡頭，長髮被風吹動，鏡頭緩慢推近
他舉起杯子喝了一口，燭光晃動，背景人群輕微走動
風吹過草原，雲影在地面上移動，鏡頭由左向右緩慢平移
```

**不好的例子**:

```
讓它動起來        ← 太模糊，會得到隨機的漂移
一個漂亮的女人    ← 這是在描述圖片，不是描述動作
```

寫得越具體越穩。動作講一到三個就好,塞太多它會顧不過來。

### 其他幾個選項

| 選項 | 說明 |
| --- | --- |
| **解析度** | `480p` 快,`720p` 慢 2～3 倍但細節好。先用 480p 試,滿意了再用 720p 重跑 |
| **長度** | 幀數。`81 幀 ≈ 5 秒`。越長越慢、越吃顯存 |
| **種子** | `-1` 是每次隨機。生出滿意的就把 seed 記下來填進去,同圖 + 同指令 + 同 seed = 同一支片。旁邊 `🎲` 是換一個隨機值 |
| **4 步加速** | 預設開著,快很多。關掉會慢 4～5 倍,動態稍微好一點 |
| **自訂負面提詞** | 勾了才會出現。留空就用該模型的官方預設值 |

> **省時間的做法**:先用 `480p` + `49 幀` + 4 步加速快速試幾個指令,找到有效的講法,
> 再用同一個 seed 換成 `720p` + 長一點跑最終版。

## 8. 素材庫（管理成品）

所有生成過的東西都在這個分頁。**預設只顯示縮圖,點一下才播** —— 這樣卡片一多的時候
瀏覽器不會一直在背景解碼幾十支影片,電腦不會卡。

上面那排控制:

| 控制 | 作用 |
| --- | --- |
| **自動播放** | 打開才會自動循環播放（像以前那樣）。預設**關** |
| **卡片大小** | 拉桿,140～420px,即時生效 |
| **只看星號** | 只顯示你加過星號的 |
| **清孤兒檔** | 刪掉硬碟上有檔案但沒有紀錄的影片 |
| **清空（保留星號）** | 刪掉所有沒星號的成品。**檔案會真的從硬碟刪掉**,會先問你 |

每張卡片下面有:

- **☆ / ★** —— 加星號,清空的時候會保留
- **下載** —— 存到你的下載資料夾
- **再跑一次** —— 把原本的指令和模型帶回生成分頁,種子換成隨機
- **刪** —— 刪掉這一支（影片檔也刪）

右上角會顯示總共幾支、佔多少空間。這些偏好記在瀏覽器裡,下次打開一樣。

紀錄現在存在硬碟上,**重啟 app 不會消失**。

## 9. LoRA（特定畫風或題材）

LoRA 是小的外掛模型,讓它更會畫某種東西。這是**畫質的關鍵**。

現在不用自己去網站下載再搬檔案了 —— **「LoRA」分頁可以直接搜 CivitAI**。

### 先設一把 API key（只做一次）

**搜尋不用 key,下載要。** 沒設的話 LoRA 分頁上面會有黃色提示。

1. 到 <https://civitai.com/> 登入
2. 右上角頭像 → **Account settings** → 找到 **API Keys** → 產生一把,複製
3. 打開 `桌面\anim\wan-video\.env`（用記事本就行）
4. 找到 `CIVITAI_API_KEY=` 這行,把 key 貼在等號後面,存檔
5. 關掉兩個黑視窗,重新雙擊 `start.bat`

### 然後就在網頁上找

打「LoRA」分頁:

- 搜尋框打關鍵字（留空 = 看熱門），按 Enter 或「搜尋」
- **相容範圍** 預設「只看完全相容」—— 只顯示和你當前模型對得上的
  （Wan 2.2 I2V 有 380 多支）。找不到想要的就放寬成「含可能相容」
- **只看 NSFW** / **模糊預覽圖** 兩個開關,設定會記住
- 每個檔案右邊一顆「**裝**」,按下去就下載到對的資料夾,已經裝過的顯示「已裝」
- 下面「已安裝的 LoRA」可以看觸發詞、來源連結,或刪掉

### 用它

回「生成」分頁,「要套用的 LoRA」區塊會列出裝好的。勾起來、拉強度。

**兩個要注意的**:

- **Wan 2.2 是「雙專家」模型**,很多 LoRA 分成 `high` 和 `low` 兩個檔 ——
  **兩個都要裝、兩個都要勾**,程式會自動各放到對的位置
- 強度先試 **0.7～1.0**。**一次只加一支**,確認效果再加下一支 ——
  疊太多支會互相打架,畫面會爛掉

> 卡片上如果有寫**觸發詞**,把它加進你的指令裡,那支 LoRA 才會真的生效。

## 10. 出問題的時候

**先跑檢查工具。** 在同一個 PowerShell 視窗（位置還在 `wan-video`）貼:

```powershell
.\venv\Scripts\python.exe app\check.py
```

它會一項一項列出:ComfyUI 有沒有起來、每個模型裝好了沒、每個流程對不對。
有問題會直接指名是哪個檔案或哪個參數,例如:

```
✗ node 1 (UNETLoader): 'wan2.2_i2v_high_noise_14B_fp8_scaled.safetensors'
  is not a valid unet_name. Available: ...
```

看不懂就把整段貼給我。

### 常見狀況

| 你看到的 | 怎麼辦 |
| --- | --- |
| `找不到 nvidia-smi` | 沒有 NVIDIA 顯卡,或顯卡驅動沒裝。到 <https://www.nvidia.com/download/index.aspx> 裝驅動 |
| `找到的 python 是 Windows 商店的空殼` | 回第 1 步去官網裝真的 Python,記得勾 PATH |
| `找不到 Python` / `找不到 git` | 裝完之後**要把 PowerShell 視窗關掉重新開一個**,新的才看得到 |
| `Test-Path` 出現 `False` | 位置不對,要在 `wan-video` 裡面,不是外面的 `anim` |
| 網頁說「ComfyUI 還沒就緒」 | 剛啟動要等一兩分鐘。超過五分鐘就看黑視窗裡有沒有紅字 |
| 模型前面是 `·` 不是 `✓` | 那個模型還沒下載。選了會出現「先下載這個模型」按鈕 |
| `CUDA out of memory` | 在 `.env` 加 `COMFY_ARGS=--lowvram`（還不行就 `--novram`）,重啟。或降解析度 / 減長度 |
| 想用大模型但顯存不夠 | **可以用**。加 `--lowvram` 或 `--novram`,會慢但跑得動。模型分頁會告訴你加哪個 |
| CivitAI 按「裝」失敗、說要 API key | 照第 9 步設 `CIVITAI_API_KEY`,然後重啟 app |
| 卡片很多的時候網頁很卡 | 把素材庫的「自動播放」關掉（預設就是關的） |
| 生出來幾乎沒在動 | 指令太抽象,把動作和鏡頭寫具體。或把「4 步加速」關掉試試 |
| 畫面糊掉、顏色怪 | LoRA 強度太高或疊太多支,降到 0.6～0.8,或先只留一支 |
| 打開網頁是空白 | 兩個黑視窗是不是有一個被關掉了？重跑第 6 步 |
| `Unexpected token '}'` 之類的一堆紅字 | 你手上的是舊版。重新下載第 3 步的 zip —— 舊版的腳本編碼不對,Windows PowerShell 讀不了 |
| 雙擊 bat 後藍色視窗說「已保護您的電腦」 | 點「其他資訊」→「仍要執行」 |

## 附:不想開瀏覽器的用法

如果你要一次處理很多張圖,可以用「丟資料夾」模式。第 6 步改成:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-windows.ps1 -Watch
```

（或者在 `start.bat` 的捷徑後面加 `-Watch`）

然後把圖片丟進 `wan-video\data\inbox\`,成品會自己出現在 `wan-video\data\outputs\`。

指令有兩種給法:

- 建一個**同名的 `.txt`**（`貓.png` 配 `貓.txt`）,內容就是指令
- 或者**直接把指令當檔名**:`她轉頭看鏡頭.png`

處理完的原圖會被搬到 `data\inbox\done\`,所以不會重複做。
