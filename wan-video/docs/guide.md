# 使用手冊：從安裝到每一個功能

這份手冊是寫給**要把這個 app 用起來的人**，照順序讀就能從零做到每一個功能。
每一節都寫：**這是做什麼的 → 在畫面哪裡 → 一步一步怎麼按 → 要注意什麼**。

想知道某個功能**為什麼這樣設計、數字從哪裡來**，README 和 `docs/` 裡的專題文件有完整說明，
每一節最後會附連結。

> 寫給 **RTX 3080 10GB＋32GB 記憶體、Windows** 的配置（也就是你的電腦）。其他配置一樣適用，只有「該下載哪個模型」那幾段要自己換算。
>
> 最後更新：2026-11-27。

## 0. 先講清楚的四件事

1. **全部在你自己的電腦上跑。** 不用帳號、不經過任何人的伺服器，圖片和成品不會離開你的電腦。
   例外只有你**自己選**的時候：切到雲端 GPU、向 CivitAI 查資料或下載模型、用 WanGP 時接遠端語言模型。
   第 20 節列出每一種情況。
2. **沒有內容過濾，但有兩條線不做**：**真人的臉**（未經同意的深偽）和**任何未成年的描繪**。
   這不是設定選項。反推、訓練、繪師實驗室看到未成年相關的標籤會直接停下來。
3. **這個 app 是在沒有顯示卡的環境開發的。** 每一張工作流程圖都送進真的 ComfyUI 驗證過結構，
   但**沒有一張在 GPU 上真的生成過**。所以：
   - 頁面上寫的速度、「最佳參數」都是**推測值**，不是量出來的。
   - 你的電腦是第一次真正跑的地方。出錯時，把黑色視窗裡的紅字貼給我，那是最有用的線索。
4. **黑色視窗不要關。** 啟動後會開兩個黑色視窗（ComfyUI 和 app 本體），用的時候一直開著；關掉就等於關掉 app。

## 2. 你的電腦能跑什麼

先知道一個原則：**顯存（VRAM）數字是「順順跑」的建議值，不是門檻。** 顯存不夠時，ComfyUI 會把模型的一部分放到系統記憶體，
一樣跑得出來，只是比較慢。你的 32GB 記憶體就是拿來補這個的。app 不會因為顯存小而擋你，只會告訴你差多少、該加什麼參數。

### 2.1 影片模型：10GB 怎麼選

| 模型 | 建議顯存 | 下載 | 適合你嗎 |
| --- | --- | --- | --- |
| **HunyuanVideo 1.5 480p**（`hy15-480p`） | 10GB | 約 22GB | **最適合當第一個**。剛好在你的顯存內，人臉和物理自然。成人 LoRA 比 Wan 少 |
| **Wan 2.2 I2V 14B Q4**（`wan22-14b-q4`） | 12GB | 約 29GB | **成人 LoRA 生態最大**（CivitAI 上 Wan 2.2 I2V 有好幾百支）。10GB 跑得動，但要把一部分放到記憶體，會比較慢 |
| Wan 2.2 TI2V 5B（`wan22-5b`） | 12GB | 約 18GB | 輕量、原生 720p。動作的複雜度比 14B 差 |
| Wan 2.2 14B fp8／Q8、MiniMax H3、LTX-2.5 | 16～24GB | 38～44GB | 在 10GB 上非常慢。用**雲端**（第 17 節）或 **WanGP**（第 18 節，它說 H3 用 5.9GB 就跑得動） |

> **3080 不支援 fp8 運算**。fp8 版本的模型檔一樣能用（省記憶體），只是不會因此變快。

### 2.2 圖片底模：10GB 都跑得動的

SDXL 系的底模大約 7GB，**10GB 跑得很順**：

| 你要畫的 | 選這個 |
| --- | --- |
| 動漫、二次元，想用畫師標籤 | **NoobAI-XL v1.1**（認得角色，也認得畫師） |
| 動漫，想用大量成人 LoRA | **Illustrious XL** |
| 寫實成人 | **LUSTIFY! ZENITH v9**（另外有 Big Lust、CyberRealistic Pony） |
| 一般寫實（穿衣服的鏡頭） | epiCRealism XL、Juggernaut XL |
| 動漫、小模型 | Anima（5.6GB，非商用授權） |

Z-Image Turbo（約 21GB）和 Qwen-Image Edit（約 17GB）在 10GB 上會很慢，建議用雲端。

### 2.3 硬碟

一個影片模型 18～44GB，一個圖片底模約 7GB。共用的元件（文字編碼器、VAE）只下載一次。
**app 下載前會先算空間**，不夠會直接告訴你差多少（第 6 節）。

## 3. 安裝、啟動、更新

### 3.1 第一次安裝（只做一次）

1. **裝 Python 3.12**：<https://www.python.org/downloads/>。安裝畫面**一定要勾「Add python.exe to PATH」**。
2. **裝 Git**：<https://git-scm.com/download/win>，一路按 Next。
3. **下載這個 app**：
   <https://github.com/ag8ai65566/ag8ai65566/archive/refs/heads/claude/local-image-to-animation-ai-375zyw.zip>
   解壓縮，裡面的 `wan-video` 資料夾就是 app。
4. **把資料夾放在 `C:\anim` 這類地方，不要放桌面。** Windows 的「勒索軟體防護」會擋程式寫入桌面和文件夾，更新時會失敗。
   這個資料夾之後也可以隨時整個搬走，模型不用重下。
5. 進到資料夾，**雙擊 `install.bat`**。它會建立 Python 環境、裝 ComfyUI，並依你的顯存挑一個影片模型下載
   （模型幾十 GB，可能要幾個小時；中斷了重跑會從斷點接著下載）。

> 沒用過命令列的話，[`docs/windows-tutorial.md`](windows-tutorial.md) 有每一步的畫面說明。

### 3.2 每天啟動：用 `update-and-start.bat`

`update-and-start.bat` 是**一個可以放在桌面的啟動檔**。第一次執行時它會自己找 app 資料夾；
找不到的話，把 app 資料夾拖進黑色視窗再按 Enter，它會記住位置。

雙擊後有四個選項：

| 按 | 做什麼 | 什麼時候用 |
| --- | --- | --- |
| `1` | 更新後啟動 | 我說「推上去了」之後，用這個拿到新版 |
| `2` | 只啟動 | 平常每天用 |
| `3` | 只更新 | 想先更新、晚點再開 |
| `4` | WanGP | 安裝／啟動／更新自動導演（第 18 節） |

- 如果 app 還開著，更新前它會請你先關掉那兩個黑色視窗（舊程式不關，新程式就不會生效）。
- **更新沒完成就不會啟動**，畫面最後一行會寫 `UPDATE OK` 或 `UPDATE DID NOT COMPLETE` 加原因。
- 啟動後瀏覽器會自動打開 <http://127.0.0.1:8000>。

也可以用資料夾裡的 `start.bat`（只啟動）和 `update.bat`（只更新），效果一樣。

### 3.3 更新會動到什麼

只換程式碼。**`ComfyUI\`、`venv\`、`data\`（你的成品）、`models\`、`.env`（你的金鑰）、`WanGP\` 一律不動**，
所以更新不會讓你重下模型或弄丟成品。ComfyUI 本體會用 `git pull` 順便更新。

### 3.4 東西放在哪

| 東西 | 位置 |
| --- | --- |
| 成品（影片、圖片） | `data\outputs\` |
| 拖檔模式的收件匣 | `data\inbox\` |
| 模型 | `ComfyUI\models\`（LoRA 在 `ComfyUI\models\loras\`） |
| 金鑰和設定 | `.env`（用「設定」分頁改就好，不用自己開） |
| WanGP（如果裝了） | `WanGP\` |

## 4. 第一次打開：畫面導覽

### 4.1 頁首

- **在哪裡跑：本機／雲端 GPU**。預設「本機」。切到「雲端 GPU」之後按的生成會送到你租的機器（第 17 節）。
- 如果 ComfyUI 還沒起來，頁面上方會出現提示和「**幫我啟動 ComfyUI**」按鈕。第一次載入模型要一兩分鐘。

### 4.2 九個分頁

| 分頁 | 一句話 |
| --- | --- |
| **影片** | 圖＋指令 → 幾秒影片。最下面有自動導演（WanGP） |
| **圖片** | 提詞 → 圖。也有漫畫分鏡、看圖猜設定、繪師實驗室、角色包 |
| **素材庫** | 所有成品；還有「實驗（固定 seed 掃參數）」 |
| **提詞庫** | 動作／姿勢庫，以及匯入你自己的提詞範例 |
| **短劇** | 「做一段影片」的快速入口，以及一整集的分鏡、批次生成、接片 |
| **訓練角色** | 準備 LoRA 訓練資料、產生設定檔、在雲端訓練 |
| **LoRA** | 搜尋並安裝 CivitAI 的 LoRA 和底模、檢查更新 |
| **模型** | 下載影片模型、放大模型、補幀模型、ControlNet、看圖分析模型 |
| **設定** | 金鑰、ComfyUI 參數、雲端 GPU、更新 ComfyUI |

### 4.3 建議的第一個小時

1. **設定**分頁：貼上 CivitAI API key（第 5 節）。
2. **模型**分頁：下載一個影片模型（`hy15-480p`）、到「圖片」分頁選一個底模下載（NoobAI-XL 或 Illustrious），再下載「看圖分析模型」（約 380MB）。
3. **圖片**分頁：畫第一張圖（第 8 節）。
4. 在那張圖的卡片上按「**→ 做成影片**」，到**影片**分頁做第一支影片（第 7 節）。

## 5. 設定分頁：填金鑰

金鑰**只在這裡填**（或寫進 `.env`），**不要貼在聊天裡給任何人**。填進去的值在頁面上會遮起來顯示。

| 欄位 | 用在哪 | 去哪裡拿 |
| --- | --- | --- |
| **CivitAI API key** | 從 CivitAI 下載 LoRA 和寫實底模；看限制級的 CivitAI 資料和圖片 | civitai.com → 右上頭像 → Account settings → API Keys。**搜尋不用 key，下載要** |
| **Hugging Face access token** | 下載「閘門式」倉庫（例如 LTX-2.5） | huggingface.co → Settings → Access Tokens，read 權限就夠；還要先到該模型頁按同意 |
| **Runpod API key** | 租雲端 GPU | runpod.io → Settings → API Keys。**填 key 不會花錢** |
| **ComfyUI 啟動參數** | 顯存不夠時加 `--lowvram`（再不行 `--novram`） | 模型分頁會告訴你該不該加 |

金鑰只會送到它自己的網站：CivitAI key 只送 civitai.com，HF token 只送 huggingface.co，Runpod key 不會送進雲端機器。

同一頁還有：
- **雲端 GPU** 卡片（第 17 節）。
- **立刻更新 ComfyUI**：只更新 ComfyUI 本體，更新後要重開。

## 6. 模型分頁：下載模型

1. 最上面顯示你的顯卡型號和顯存。
2. 每個模型卡片寫著建議顯存、下載大小，以及**對照你實際顯卡的建議**（例如「要加 `--lowvram`，大概慢 2～4 倍」）。
3. 按**下載**：有即時進度、速度、剩餘時間，可以中途停掉，下次接著下載。
4. 下載完，影片分頁和圖片分頁的下拉選單會出現它（`✓` 已下載、`·` 還沒下載、`◐` 下載到一半、`☁` 雲端可用）。

這頁分成幾區：

| 區 | 什麼時候需要 |
| --- | --- |
| **影片模型** | 做影片一定要一個 |
| **放大模型**（約 65MB） | 圖片「生成後直接放大」、影片「放大成品」 |
| **補幀模型**（RIFE 約 22MB） | 影片「補幀」，讓 16fps 變順 |
| **ControlNet**（約 2.5GB） | 構圖鎖定、漫畫「照現成的一頁重畫」 |
| **看圖分析模型**（約 380MB） | 看圖猜設定、反推、自動逼近、繪師實驗室的未成年檢查 |

**圖片底模**是在**圖片**分頁選了底模之後，按「先下載這個底模」下載；
寫實的那幾個放在 CivitAI，要先填 CivitAI key。

**硬碟空間**：按下載時，app 會先算「這次加上排隊中的下載還要多少」，跟硬碟剩餘空間比，
還要多留 2GB。不夠就直接告訴你差多少，不會下載到 90% 才失敗。
下載到一半硬碟滿了，已下載的部分會留著，清出空間後再按一次就接著下載。

**LTX-2.5** 是閘門式倉庫：要先在 <https://huggingface.co/Lightricks/LTX-2.5> 登入按同意，**而且**在設定分頁填 HF token，少一件都會失敗。
**MiniMax H3** 的授權排除美國、歐盟、英國、韓國，下載前會要你確認。

## 7. 做第一支影片（影片分頁）

### 7.1 基本步驟

1. **放圖**：把圖拖進框裡、點框選檔案，或直接 **Ctrl+V** 貼上。
2. **寫指令**：描述「怎麼動」和「鏡頭怎麼走」，中英文都可以。
3. **選模型**：沒下載的會顯示「先下載這個模型」。
4. **選解析度、長度（秒）**：長度用秒選，下拉會寫實際幀數，例如「5 秒（81 幀 @16fps）」。
5. 按**生成**。成品出現在下面「最近」，卡片上寫實際長度和這次花了多久。
   要停下來就按**中斷**。

### 7.2 指令怎麼寫

這些模型吃「動作＋鏡頭」的句子：

```
她慢慢轉頭看向鏡頭，長髮被風吹動，鏡頭緩慢推近
he raises the glass and drinks, warm candlelight flickering, slow dolly in
```

- **越具體越穩。** 只寫「讓它動起來」會得到隨機的晃動。
- 動作太小、幾乎靜止 → 把動作寫得更明確，或關掉「加速」。
- 想要可以重現的結果：把**種子**從 `-1`（隨機）改成固定數字。同一張圖＋同一句指令＋同一個種子＋同一個模型 → 同一支片。🎲 按鈕換一個隨機種子。

### 7.3 其他選項

| 選項 | 作用 |
| --- | --- |
| **加速**（4 步 Lightning） | 快很多。動作有時會變小；不滿意就關掉試試 |
| **自訂負面提詞** | 留空就用該模型官方的預設值 |
| **出片後處理 → 補幀** | 2 倍或 4 倍，讓 16fps 變順（長度不變，不是慢動作） |
| **出片後處理 → 放大成品** | 用放大模型把整支影片放大 |
| **要套用的 LoRA** | 勾選、拉強度。**Wan 2.2 有 high／low 兩個專家**，CivitAI 上分兩個檔的 LoRA 兩個都勾 |

LoRA 強度先從 0.7～1.0 試；疊太多支會互相打架，一次加一支。

### 7.4 卡片上的按鈕

- **再跑一次**：同樣的設定、換新種子。
- **同種子微調**：種子和設定都不變，只改你想試的那一個，做 A/B 比較。
- **接著修**（圖片卡片）：拿這張當來源圖再畫一次。
- **→ 做成影片**（圖片卡片）：直接把圖送到影片分頁。

## 8. 做圖片（圖片分頁）

### 8.1 基本步驟

1. **選底模**（第 2.2 節）。沒下載的按「先下載這個底模」。
2. **寫提詞**。底模不同，寫法不同（下一段）。
3. 選**尺寸**、**一次幾張**（最多 16 張，同設定、不同種子，一次挑好的）。
4. 按**生成**。

### 8.2 每個底模的寫法（重要）

| 底模 | 提詞寫法 |
| --- | --- |
| NoobAI | danbooru 標籤，照順序：`1girl, 角色, 作品, artist:畫師, 其他標籤` |
| Illustrious | danbooru 標籤（`1girl, long hair, sitting`），句子效果差 |
| Pony 系 | 開頭要有 `score_9, score_8_up, score_7_up`（app 會自動加） |
| 寫實底模（LUSTIFY、Juggernaut…） | **英文句子**描述場景和光線。`1girl`、`cowboy shot` 這種標籤它們看不懂 |

CLIP skip、sampler 這些 app 已經照每個底模的建議設好，不想調就不用碰。

**加重語法**：`(詞:1.3)` 加重、`(詞:0.7)` 減弱。游標停在一個詞上按 **Ctrl+↑／↓** 會自動調。
NovelAI 的 `{{詞}}`、`[詞]`、`1.3::詞::` 在這裡**沒有效果**；從 NovelAI 圖片讀進來的提詞會自動轉換（第 10 節）。

**隨機變化**：`{紅|藍|綠}裙子` 每張隨機挑一個；`{2$$長髮|貓耳|眼鏡}` 挑兩個。一次生 8 張就有 8 種組合，
按「看看隨機變化」先預覽。按「**提詞語法**」看完整說明。

**提詞健康度**：提詞框下面那一行會即時提醒你常見問題，例如 SDXL 用 512×512（圖會很爛的主因）、
Pony 的 score 詞用在別的底模上、同一個詞同時在正面和負面。

### 8.3 角色包

圖片分頁的「🎤 角色包」：**選期別 → 點成員 → 點衣裝 → 按「填入提詞」**。
它會一次把觸發詞和衣裝標籤填好、換上作者建議的負面提詞、**自動勾選那支角色 LoRA 並設好強度**；
底模不對會提醒你並提供一鍵切換。內建的是 Hololive Collection（75 位、319 套衣裝，要 Pony 底模）。

### 8.4 風格靈感庫、常用提詞、畫師清單

- **風格靈感庫**：22 組動漫＋7 組攝影的畫面配方（光線、構圖、氛圍）。**不是模型，不用下載**，只是幫你打好的一串提詞。
  套用前會先給你看會改哪些詞。
- **常用提詞**：316 個分類好的標籤（表情、手勢、服裝狀態、姿勢、視角…），中英都能搜，點一下加進提詞。
- **畫師清單**：52 位畫師的風格說明。前綴會跟著底模自動換（NoobAI 用 `artist:名字`、Illustrious 用 `by 名字`；Pony 不吃畫師名）。
  不知道要用哪位畫師的話，用**繪師實驗室**（第 11 節）。

### 8.5 進階微調（不動也能用）

| 區塊 | 有什麼 | 一句話 |
| --- | --- | --- |
| 基本 | 步數、CFG、Sampler、Scheduler、CLIP skip | 預設值照底模建議填好 |
| **以圖生圖** | 放一張「來源圖」＋「重畫強度」 | 拉桿旁會寫改多少：0.35 以下只改材質細節、0.5～0.65 保構圖換風格、0.8 以上幾乎整張重畫 |
| **放大與重繪** | 倍率、重繪強度、步數、放大方式、生成後直接放大 | 高解析重繪：先畫一般大小再放大重畫細節。「生成後直接放大」只放大不重畫 |
| **構圖鎖定（ControlNet）** | 一張參考圖 → 照它的構圖畫別的 | 要先下載 ControlNet。「管到幾成」0.75 最常用：前 75% 照構圖、後面放手畫細節 |
| **參考圖（IP-Adapter）** | 一張圖 → 學它的畫風／構圖 | **沒有那支 LoRA 時的一次性 LoRA**，只限 SDXL 系。學人臉身分的 FaceID 刻意不提供 |
| **畫質補丁** | FreeU、PAG、Rescale CFG、分塊解碼 | 分塊解碼可以省顯存 |

### 8.6 LoRA

「要套用的 LoRA」清單：勾選、拉強度。每支可以按 🔗 把「對畫面」和「對文字理解」兩個強度拆開調。
點清單上的**觸發詞**會自動加進提詞並勾選那支 LoRA。

### 8.7 用一句話改圖（Qwen-Image Edit）

1. 底模選 **Qwen-Image 2.1 Edit**（建議雲端）。
2. 「以圖生圖」放要改的圖。
3. 提詞寫要改什麼：「把衣服換成紅色洋裝」「背景換成夜晚」。
4. 參考圖區可以再放第二張（例如要換上的那件衣服）。

人和畫風會保留。授權只限研究／評估，不能商用。

## 9. 漫畫分鏡

### 9.1 畫一頁

1. 圖片分頁上方切到「**漫畫分鏡**」。

## 10. 看圖猜設定／反推

圖片分頁右上有兩個入口：

- **🔍 看圖猜設定**：選一張你電腦上的圖。
- **🔗 CivitAI 圖片連結**：貼 CivitAI 圖片頁的網址。

結果頁會把「**事實**」（檔案或 CivitAI 上寫的）和「**意見**」（模型看圖猜的）分開標示。

### 10.1 檔案裡寫的（精確）

這些來源會把生成設定寫進圖片檔，讀得出來就是**精確的**，不用下載任何東西：

| 來源 | 讀得到什麼 |
| --- | --- |
| **ComfyUI** | 整張流程：提詞、負面、底模、**每支 LoRA 和強度**、種子、步數、CFG、sampler、尺寸 |
| **A1111／Forge**（含 CivitAI 生成器） | 同上，加上模型和 LoRA 的雜湊值、CivitAI 版本編號 |
| **NovelAI** | 提詞、負面、種子、步數、scale、sampler、尺寸、V4 分角色提詞。**連網站把文字欄位刪掉、只剩透明通道裡那份備份的圖也讀得到**（前提是圖還是原始 PNG） |

- NovelAI 的提詞會**自動換成這邊的加重寫法**（`{詞}` → `(詞:1.05)` 等）。NovelAI 的模型不公開，所以拿去 NoobAI／Illustrious 用時，**種子和取樣器換了模型就不會一樣**，但提詞和畫師標籤可以直接用。
- 會告訴你**那些 LoRA 你有沒有裝**，沒裝的附 CivitAI 搜尋連結。
- 按「**套用到下面的設定**」把全部帶進圖片分頁。

> 截圖、轉貼過、存成 JPG 的圖，參數通常已經不見了。這時只能用下面的「看圖猜」。

### 10.2 看圖猜的（意見）

沒有參數的圖，用**看圖分析模型**（要先在模型分頁下載）列出 danbooru 標籤，直接是可以貼進提詞的格式。
可以勾選只要「角色名／外觀／服裝／動作構圖背景」其中幾類，例如「只要動作和背景，角色用我自己的」。

**從像素沒辦法知道是哪一支 LoRA 畫的**，沒有任何工具做得到。頁面上「觸發詞對得上的 LoRA」只是參考。

### 10.3 CivitAI 圖片連結

1. 圖片分頁右上「**🔗 CivitAI 圖片連結**」。
2. 貼上 `https://civitai.com/images/數字`，按「讀取」。
3. 作者有附生成資料的話：提詞、種子、取樣器，以及**模型和每支 LoRA 的版本編號**都是精確的。
4. 圖片本身也會抓下來，下面的看圖猜、自動逼近、比對都能照常用。

限制級的圖要先在設定分頁貼 CivitAI API key，否則 CivitAI 會說找不到。

### 10.4 反推：照這樣做會最像

結果頁下半部：

- **建議的底模、尺寸、提詞**。
- **檔案點名的模型和 LoRA（到 CivitAI 查出來的）**：有雜湊或版本編號的是精確比對；只有檔名的會標「可能不是同一個」。
- **找畫風／角色相近的 LoRA**：用看到的標籤去 CivitAI 搜，再把每支 LoRA 的範例圖跟你的圖比對排名（約 30～60 秒）。
  分數是「範例圖跟你的圖多像」，**不是**「原圖是用它畫的」。
- **拿原圖當起點**：把原圖設成以圖生圖的來源（重畫強度 0.45），構圖和顏色照原圖、細節重畫。要「幾乎一模一樣」用這個。
- **拿原圖當參考圖**：用 IP-Adapter 只學畫風，內容和構圖照提詞。

### 10.5 生完比對

照著配方生一張之後，按「**比對最新一張成品**」：告訴你跟原圖差多少、少了／多了哪些東西，
一鍵把少的加進提詞、多的加進負面提詞，再生一次。

### 10.6 自動逼近與基準測試

**自動逼近**把「生 → 比 → 改」自動一輪一輪跑：

1. 設定最多幾輪、每輪幾張、目標分數；要不要「從原圖開始」。
2. 按「**開始自動逼近**」。每輪比「內容、畫風、構圖」三種分數，少的標籤加進提詞、多的放進負面、構圖跑掉就降低重畫強度。
3. 達標、跑滿、或連續兩輪沒進步就停。每輪的圖和分數都列出來。
4. 按「套用這條最好的那組」帶回圖片分頁。

用的是圖片分頁**目前選的底模、尺寸和 LoRA**。有裝繪師實驗室的畫風模型（Kaloscope）時，畫風分數會改用它。

**基準測試**：同一張圖、同一個起始提詞，「只用提詞」和「從原圖開始」各跑一次，分數並排，用你自己的數字回答「哪個比較像」。

## 11. 繪師實驗室

圖片分頁右上「**🎨 繪師實驗室**」。解決兩件事：**不知道有哪些畫師標籤**，以及**畫師可以無限組合、沒辦法一個一個試**。

> 需要能吃畫師標籤的底模：**NoobAI 或 Illustrious**。Pony 和寫實底模不吃。
> 「看圖認畫師」和「自動評分」要下載 Kaloscope 3.0（169MB，在你電腦上用 CPU 跑，約 1 秒一張）；實驗室打開時會有下載按鈕。

### 11.1 ① 想要的畫風（選填，有了才能自動排名）

三種放法：

- **選圖**：一次可以選很多張。
- **選整個資料夾**：瀏覽器會把裡面的圖傳上來。
- **貼資料夾路徑**（例如 `D:\圖\某種畫風`）＋「判斷這個資料夾」：不用上傳，直接讀。

**同一種畫風的圖，放越多張越準。** 每張圖都帶著自己的題材和構圖，很多張平均起來，題材互相抵銷，剩下的才是畫風。
用真實作品量的結果：

| 放幾張 | 單張 | 兩張 | 三張以上 |
| --- | --- | --- | --- |
| 真正的畫師排第一 | 70～86% | 92～100% | 99～100% |

3～10 張就夠，最多用 60 張（更多會平均抽樣）；只看那一層資料夾，不看子資料夾。

多張的時候，它也會**檢查這批圖是不是同一種畫風**：
- 每張縮圖下面有它跟整批平均畫風的相似度。明顯偏低的標「**不像**」，按「拿掉標『不像』的 N 張再判斷」重算；
  也可以自己取消勾選，按「只用打勾的重新判斷」。
- 整批彼此都不像（例如兩位畫師各半），會直接說「看起來不只一種畫風」，請你分開成不同資料夾。

結果會列出最像的畫師標籤和分數。勾好按「**把勾的加進清單**」。分數是模型的把握，不是證據；低分的也可能混得出來。

### 11.2 ② 要試的畫師

一次貼多少都行（最多 200 位），逗號或換行分開。這些寫法都看得懂：
`artist:wlop`、`by hiten`、`1.2::artist:mika pikazo ::`、`{{ask (askzy)}}`、`(artist:ciloranko:1.1)`。

- 「**加入內建清單**」：加入畫師清單裡的 52 位。
- 「**檢查清單**」：整理格式、算人數；有下載 Kaloscope 的話會抓拼錯的（「是不是 hiten_(hitenkei)？」）。

### 11.3 ③ 試畫設定 → 每位畫師畫一張

1. 測試提詞：對每位畫師都一樣，越中性越好比（預設就是一句中性的人物描述）。
2. 種子：留空隨機；想跟上次比就填同一個。
3. 「小圖快速試（768×1024）」：建議勾著，一百位畫師就是一百張圖。
4. 按「**開始：每位畫師畫一張**」。

每位畫師用**同一句提詞、同一個種子**各畫一張，另外加一張「不加畫師」當對照，只有畫師不同，一眼就能比。
有目標畫風的話，每張會自動算相似度並排名。參考值：同一位畫師的作品，目標是單張圖時約 60%、多張合併時約 75～80%；無關的畫師約 20%。

可以隨時按「停止」，生好的都會留著。底模、步數、LoRA 用的是圖片分頁目前的設定。

### 11.4 ④ 把畫師混起來

1. 在喜歡的格子打 ★；都沒打星就取分數（或清單）前幾名。
2. 選每組 2 人／3 人、第一批幾組；有目標畫風的話還有「再自動調整幾輪、每輪幾組」（預設 5 輪）。
3. 按「**開始組合**」。

自動調整的每一輪：先把目前最像的那組**每個權重各往上、往下試一格**（有系統地試，不靠運氣），
剩下的名額隨機探索（換一位、加一位、拿掉一位）。連續兩輪沒進步就停。

每個組合都可以「**套用到提詞**」、「複製」，或「**複製成 NovelAI 寫法**」（`1.2::artist:名字 ::`）。

### 13.1 動作／姿勢庫

### 13.2 我的範例（匯入你自己的收藏）

「**匯入檔案**」：支援 `.txt .md .csv .tsv .json .jsonl .docx .pdf`。
它會自己判斷檔案怎麼分段（一行一個、空行分隔、`Prompt:`／`Negative:` 標籤式、A1111 參數區塊、JSON／CSV…），
**匯入前先給你看抓到什麼**，確認了才存。重複的自動略過，Big5、UTF-16 編碼都讀得出來。
檔案只在你電腦上處理。

之後可以搜尋（空白分隔＝全部符合）、加星號、一鍵帶進圖片或影片的提詞框。

## 14. LoRA 分頁

### 14.1 找和裝

1. 搜尋框輸入關鍵字，選排序和期間。
2. 「用在哪」：**影片模型**或**圖片底模**（篩選會跟著換，影片的 LoRA 對圖片沒用，反之亦然）。
3. 「找什麼」：LoRA 或底模 Checkpoint。
4. 「相容範圍」：預設只顯示和你目前模型完全相符的。
5. 每個檔案一顆「裝」，直接下載到 `ComfyUI\models\loras\`。觸發詞和來源會一起存下來。

「只看 NSFW」和「模糊預覽圖」兩個開關會記住。**下載要 CivitAI key，搜尋不用。**

### 14.2 已安裝的 LoRA

一面預覽圖牆。沒有預覽圖的可以按「封面」用自己生的圖當封面。上面的篩選框可以搜名字、底模、觸發詞。

### 14.3 檢查更新

「**檢查更新**」一次看三件事：這個 app、ComfyUI、你裝的 LoRA／底模在 CivitAI 上有沒有新版。有新版的卡片會變黃框並有「下載新版」。

### 14.4 手動放 LoRA

把 `.safetensors` 丟進 `ComfyUI\models\loras\`，回網頁就會出現，不用重啟。

## 15. 短劇分頁

### 15.1 做一段影片（快速入口）

最上面：上傳圖 → 選模型 → 打指令 → 生成。不用建專案。

### 15.2 排一整集

往下拉，一個專案＝一集：

1. **第 0 步 鎖規格**：選「影片模型＋原生幀率」的組合，整集一致。
2. **第 1 步 資產層**：卡司表，每個角色的觸發詞、鎖定服裝、專屬 LoRA。
3. **第 2 步 分鏡表**：一列一顆鏡頭，即時算總長、鏡頭中位數、台詞字數。
4. **分鏡健康度**：幀率對不上、鏡頭太長、角色沒 LoRA、模型沒下載…都會列出來。
5. **做這顆**：把關鍵幀提詞組好，一鍵送到圖片分頁。
6. **整集**：① 排完所有關鍵幀 →（你挑）→ ② 排完所有影片 →（再挑）→ ③ 接成一支影片。
   **它不會替你採用任何候選**，每一步都要你自己選。
7. **接成一支影片**需要電腦上有 ffmpeg（找不到會告訴你去哪下載）。

完整教學：[`docs/short-drama.md`](short-drama.md)。

## 16. 訓練角色分頁

**要同一個人每張都長一樣，最可靠的是自己的角色 LoRA。** 這個分頁一步一步帶你：

1. **這個角色是誰**：觸發詞（像 `s1vra_person` 這種不是真實單字的詞）、底模架構、訓練器。
2. **要準備哪些圖**：景別、角度的配比建議。
3. **標註怎麼寫**：寫進標註的是「會變的」（姿勢、服裝、景別、光線）；**臉不要寫**，臉就是要學的東西。
4. **檢查這組資料**：貼訓練圖資料夾路徑 → 「檢查」，會把問題列出來（讀不開的檔、張數太少或太多、解析度不夠、景別全部一樣、沒有標註…）。
5. **產生設定檔**：kohya_ss／ai-toolkit／diffusion-pipe／OneTrainer 的設定檔與執行指令。

**只有一張角色圖？** 用「**從一張圖生一組訓練圖**」：選角色圖、底模、張數 → 開始生，生出不同角度、姿勢、表情的圖，勾好的放進訓練資料夾，標註自動寫好。

**本機不訓練**（10GB 練 SDXL LoRA 太勉強），可以用「**在雲端訓練（Runpod）**」：
用上面的資料夾、觸發詞、輸出檔名，在租的機器上訓練，完成後「**抓回本機**」。
開始前要勾選確認：原創角色或有權使用、**不是未經同意的真人、沒有未成年人物**；有看圖分析模型時，每張訓練圖都會檢查。
這條路**還沒在真的 GPU 上跑過**，第一次會先安裝訓練程式（幾分鐘），出錯時訓練紀錄會說原因。

教學：[`docs/photoreal.md`](photoreal.md)。

## 17. 雲端 GPU（Runpod）

顯卡不夠的模型（MiniMax H3、LTX-2.5、Wan fp8）可以送到租來的顯卡上跑，**網頁操作完全一樣**。

### 17.1 開始

1. 到 [runpod.io](https://www.runpod.io) 註冊、儲值（開機前帳戶至少要有 1 小時的額度），建一把 API key（權限 All）。
2. **設定**分頁「Runpod API key」貼上、存起來。
3. 同一頁「雲端 GPU」：選 Secure（穩定）或 Community（便宜）→「**列出現在能租的顯卡**」→ 選一張（24GB 以上標「影片 OK」）→ 設定模型硬碟大小 →「**開機**」。開機前會再確認一次價格。
4. 頁首「在哪裡跑」切到**雲端 GPU**。之後的生成都送過去。

模型不用自己搬：缺的檔案雲端機會自己下載（資料中心的速度）；只有你電腦上才有的（自己訓練的 LoRA）才從你這裡上傳。

### 17.2 錢

- **按秒計費**。卡片上顯示開了多久、大約多少錢、多久後自動關機（金額是用牌價估的，以 Runpod 帳單為準）。
- **閒置**超過設定分鐘數（預設 15）自動關機。
- 就算你直接關掉電腦，雲端機在 30 分鐘沒收到 app 訊號、而且沒有工作在跑時也會自己關機。
- 模型放在獨立的**網路硬碟**，關機不會刪，但**沒開機也會收錢**（約每 GB 每月 0.07 美元）。不用了在同一頁「**刪除硬碟**」。

### 17.3 隱私

- 切到雲端時，你的輸入圖、提詞、成品會經過你租的那台機器。
- 雲端的 ComfyUI 只認這台電腦開機時產生的隨機憑證，別人拿到網址也進不去。
- **還沒有實際租過 Runpod、也沒在雲端生成過**。第一次真正開機會在你的帳號上發生；開機紀錄會即時顯示在卡片上，有問題貼給我。

## 18. 自動導演：WanGP

這個 app 生成的是**一段**：你寫指令、它照做。要「**給一張圖，它自己判斷怎麼動、一段接一段拍、自己檢查、剪成一支**」，
用的是另一個免費開源的 app —— [WanGP](https://github.com/deepbeepmeep/Wan2GP) 的 **Showrunner**。這個 app 幫你裝它、開它。

### 18.1 安裝（第一次）

任選一個入口：
- 影片分頁最下面「🎬 自動導演（WanGP）」→「安裝」
- app 資料夾裡的 `wangp.bat`
- `update-and-start.bat` 按 `4`

它會依序：
1. 檢查 Git、顯卡驅動（**要 580 版以上**，太舊會先提醒你去更新）、硬碟空間。
2. 沒有 Python 3.11 就問你要不要用 winget 自動安裝（WanGP 在 RTX 30 系列上要 3.11；這個 app 的 3.12 不受影響，兩個可以並存）。
3. 把 WanGP 下載到 app 資料夾的 `WanGP\`，用 WanGP 自己的安裝程式（自動模式）裝好。

安裝視窗會一直開著到你按任意鍵，看得到成功或失敗的原因。

> **這套安裝腳本沒有在 Windows 上實際跑過。** 裝不起來的話，改用 WanGP 官方的圖形安裝器
> [WanGPManager.exe](https://github.com/deepbeepmeep/WanGP/releases/latest/download/WanGPManager.exe)，
> 選 Use existing installation 指到 `WanGP\` 資料夾。

### 18.2 啟動

按「**啟動**」：會先請這邊的 ComfyUI 把顯存讓出來（兩個 app 共用一張顯卡），再開一個黑色視窗跑 WanGP，好了自動打開 <http://127.0.0.1:7860>。
**同一時間只讓一邊生成。**

### 18.3 給一張圖，讓它拍成一支片

1. WanGP 上方打開 **Showrunner**，選格式（Short film 或 Anything），取名。
2. Brief 寫一句想法，把圖拖進 **Cast**（人物）或 **References**（參考），設定總長度。
3. 按 **Plan with the showrunner**：它先把每一鏡寫好給你看，想改就改。
4. 按 **Shoot**：逐鏡生成、自己檢查每一段、重做失敗的，最後剪成一支，在 **Deliver** 看。

導演用的是本機語言模型；10GB 顯卡它會自動選 Qwen3.8 的 Bonsai 版（不到 6GB）。
WanGP 的 Configuration > Deepy / Prompt Enhancer 可以改選 **Bonsai 2.5**（官方說它專門加強了 Showrunner 這種多步驟工作）。

只要一段：WanGP 一般生成頁選圖生影片模型，用 Prompt Enhancer 讓它看圖寫提詞；要更長就開 Sliding Window。

### 18.4 要注意的

- **成人內容只留在本機**：WanGP 的助理可以接遠端語言模型（Codex、Claude Code 等），也可以開網路搜尋，預設都關閉。**做成人內容時不要打開**。
- WanGP 的 MCP 伺服器預設用 8000 port，跟這個 app 衝突。要開 MCP，先在它的 Configuration > Agents 改 port。
- 未成年、真人臉的界線在 WanGP 裡一樣適用。

## 19. 拖檔案模式（不開瀏覽器批次生成）

1. 用 `start.bat -Watch` 啟動（多開一個監看視窗）。
2. 把圖片丟進 `data\inbox\`。
3. 指令寫在同名的 `.txt`（`cat.png` → `cat.txt`）；沒有 `.txt` 的話，**檔名本身就是指令**。
4. 成品出現在 `data\outputs\`，處理完的原圖搬到 `data\inbox\done\`。

用哪個模型看 `.env` 的 `WATCH_MODEL`（留空就用 `MODEL`）。

## 20. 隱私與安全：什麼東西會離開你的電腦

| 情況 | 送出什麼 | 送到哪 |
| --- | --- | --- |
| 平常在本機生成 | **什麼都不送** | — |
| 下載模型 | 下載請求（和該網站的 key） | Hugging Face／CivitAI |
| LoRA 分頁搜尋、檢查更新 | 搜尋字詞、你裝的檔案的頁面編號 | CivitAI |
| 反推：查 CivitAI、找相近 LoRA | 模型名稱／雜湊／標籤（**不送你的圖**） | CivitAI |
| 🔗 CivitAI 圖片連結 | 那張圖的編號 | CivitAI |
| 切到雲端 GPU | 輸入圖、提詞、成品 | 你租的 Runpod 機器 |
| WanGP 接遠端 LLM（預設關） | 對話和圖 | 你設定的服務 |

**別的網頁不能操作這個 app**（2026-11-27 起）：你瀏覽的任何網站都不能偷偷叫這個 app 刪成品、下載、開 PowerShell 或租雲端 GPU。
要用 `http://127.0.0.1:8000` 或 `http://localhost:8000` 打開；真的要用電腦名稱連進來，在 `.env` 加 `ALLOWED_HOSTS=那個名稱`。

**金鑰**：只在設定分頁或 `.env` 填，頁面上遮起來顯示，不要貼在聊天裡給任何人。

## 21. 出問題的時候

### 21.1 先看黑色視窗

兩個黑色視窗（ComfyUI 和 app）裡的紅字通常直接說了原因。**把紅字整段貼給我**是最快的。

### 21.2 檢查工具

在 app 資料夾開終端機：

```powershell
.\venv\Scripts\python.exe app\check.py
```

逐項列出每個模型的安裝狀態，並把每個工作流程拿去跟你的 ComfyUI 對照，哪個節點不對會指名道姓。

### 21.3 常見狀況

| 狀況 | 怎麼辦 |
| --- | --- |
| `CUDA out of memory` | 設定分頁「ComfyUI 啟動參數」加 `--lowvram`（還不行就 `--novram`），重開；或降解析度、縮短長度、換小模型 |
| 網頁說 ComfyUI 還沒開 | 按「幫我啟動 ComfyUI」；第一次載入要一兩分鐘 |
| 選單裡模型標 `·` | 還沒下載，去模型分頁 |
| CivitAI 下載 401 | 沒填 CivitAI API key |
| LTX-2.5 下載 401 | 要在 Hugging Face 頁面按同意，**而且**填 HF token |
| 「硬碟空間不夠」 | 刪掉用不到的模型，或把整個 app 資料夾搬到大硬碟（模型不用重下） |
| 「硬碟滿了，下載停在這裡」 | 清出空間後再按一次下載，會接著下載 |
| 影片動作很小、幾乎不動 | 指令寫得更具體；或關掉「加速」 |
| 畫面糊掉、顏色壞掉 | LoRA 強度太高或疊太多支，降到 0.6～0.8 |
| 圖很爛、雙頭 | 看提詞健康度；SDXL 不要用 512×512 |
| 「這個請求是別的網站送來的，已經擋下」 | 正常的保護，直接在這個 app 的頁面上操作 |
| 「只接受用本機位址打開」 | 用 `http://127.0.0.1:8000` 開；或在 `.env` 加 `ALLOWED_HOSTS` |
| `update.bat` 說 `Access to the path ... is denied` | 資料夾在桌面或 OneDrive 同步中。整個搬到 `C:\anim` 再更新 |
| WanGP 說顯存不夠 | 先把這個 app 的兩個黑色視窗關掉，再開 WanGP |

更多問答：[`docs/faq.md`](faq.md)。

## 22. 名詞小辭典

| 名詞 | 意思 |
| --- | --- |
| **底模**（checkpoint） | 會畫畫的模型本體，一次只能用一個 |
| **LoRA** | 疊在底模上的小檔案，教它一個特定角色、畫風或動作 |
| **觸發詞** | 啟動某支 LoRA 的那個詞 |
| **提詞／負面提詞** | 要畫什麼／不要畫什麼 |
| **種子**（seed） | 隨機數。同樣的設定＋同樣的種子 → 同樣的結果。`-1` 是每次隨機 |
| **步數**（steps） | 一張圖算幾步；多不一定好，照底模建議 |
| **CFG** | 多聽提詞的話；太高顏色會燒壞 |
| **Sampler／Scheduler** | 算圖的方法；照底模建議 |
| **CLIP skip** | 動漫底模多用 -2；app 已經設好 |
| **重畫強度**（denoise） | 以圖生圖時改多少：0 不改、1 全部重畫 |
| **ControlNet** | 照參考圖的構圖（線稿、深度、姿勢）畫 |
| **IP-Adapter** | 照參考圖的畫風或內容畫，像一次性的 LoRA |
| **看圖分析模型**（tagger） | 看圖列出 danbooru 標籤的模型 |
| **danbooru 標籤** | 動漫底模訓練時用的標籤寫法，例如 `1girl, long hair` |
| **Lightning／加速** | 4 步就出片的加速 LoRA |
| **補幀** | 在影格之間補畫，讓影片更順 |
| **gated（閘門式）倉庫** | 要登入並按同意才能下載的模型 |

更白話的版本：[`docs/start-here.md`](start-here.md)。
