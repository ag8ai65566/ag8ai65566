# 從零開始：底模、畫風、LoRA 到底是什麼

寫給**完全沒碰過這類工具**的人。看完你會知道自己要下載什麼、下載幾個、放哪裡。

---

## 一、三個名詞，一句話各講完

| 名詞 | 是什麼 | 要下載嗎 | 多大 |
|---|---|---|---|
| **底模**（checkpoint） | **那個會畫畫的模型本體**。沒有它什麼都做不了 | **要，至少一個** | 6～7 GB |
| **LoRA** | 一個小檔案，**疊在底模上面**教它一件它本來不會的事 | 要，但看你需不需要 | 50～300 MB |
| **畫風配方** | **不是模型，不用下載。** 是這個 app 幫你打好的一串提詞 | **不用** | 0 |

### 用做菜比喻（這個比喻是準的）

- **底模 = 廚師。** 你請的是一位西餐廚師還是一位日料廚師，決定了端出來大概是什麼樣的東西。
  **一次只能請一位。**
- **LoRA = 給廚師的一張特定食譜。** 「這道菜要照這個樣子做」——某個角色的長相、某種畫風。
  一位廚師可以同時拿好幾張食譜。**食譜不能單獨用，一定要有廚師。**
- **畫風配方 = 你點餐時講的話。** 「我要五分熟、少鹽、擺盤簡單一點」。
  它不是食材也不是人，**它只是話**，所以不用下載。

## 二、你到底要下載什麼

### 最少：一個底模。就這樣

裝好 app 之後,**只下載一個底模就能開始用了**。到「模型」分頁,按一個下載鍵。

選哪一個看你要畫什麼:

| 你要畫的東西 | 選這個 | 為什麼 |
|---|---|---|
| **動漫、二次元角色** | **NoobAI-XL** | 它認得幾千個動漫角色的名字,也認得畫師 |
| **寫實真人（含成人）** | **LUSTIFY! ZENITH v9** | 專門為寫實成人內容微調的 |
| 寫實真人（穿著衣服的鏡頭） | epiCRealism XL 或 Juggernaut XL | 通用寫實 |

> **不要一次下載全部。** 一個 7GB,九個就是 63GB,而你一次只會用一個。
> 先下載一個,用一陣子覺得不夠再加。

### 然後：影片模型（如果你要做影片）

圖片和影片是**兩套不同的模型**。要讓圖片動起來,還要下載一個影片模型。
新手就選 **Wan 2.2 I2V 14B**（`wan22-14b-fp8`,或顯卡小一點選 `wan22-14b-q4`)。

### 最後：LoRA（如果你需要）

**LoRA 是選配的,不是必需的。** 你什麼時候會需要它:

- 你要**同一個角色出現在很多張圖裡**,長相要一樣 → 需要角色 LoRA
- 你想要某種底模本來畫不出來的特定風格 → 需要風格 LoRA
- 你要某個特定的動作或姿勢 → 可能需要

只畫幾張隨機的圖?**不需要 LoRA。**

## 三、「畫風」為什麼不用下載

這是最容易誤會的一個,而且我們把它取名叫「畫風」可能就是誤會的來源。

在「圖片」分頁按「風格靈感庫」,你會看到一排東西:「清爽官方動畫 Key Visual」、
「汽車旅館夜戲」…… 那些**不是模型**。點下去它做的事是:

```
把一串提詞加到你的提詞後面
```

就這樣。比如點「汽車旅館夜戲」,它會加上:

```
cheap motel room at night, warm practical lamp light, low key lighting,
deep shadows, 50mm lens, visible skin texture and pores, subtle film grain
```

**這些就是英文單字而已。** 它們不占硬碟、不用下載、按了立刻生效。
它存在的理由是:這些詞是查證過哪些真的有用的,你不用自己去猜。

> 所以正確的理解是:**「畫風配方」= 幫你打好的提詞範本**。
> 如果它叫「提詞範本」你大概一開始就懂了。

**而且動漫和寫實的配方是分開的兩套**,因為它們的詞根本不通用
（下一節解釋為什麼）。

---

## 四、一個很多人踩的坑：底模認得的詞不一樣

這件事沒人告訴你的話,一定會踩。

**動漫底模**（NoobAI、Illustrious、Pony）是拿 danbooru 那種**標籤**訓練的,
所以它認得的是這種寫法:

```
1girl, long hair, upper body, cowboy shot, school uniform
```

**寫實底模**（LUSTIFY、epiCRealism、Juggernaut）是拿**英文句子**訓練的,
所以要這樣寫:

```
one adult woman, long hair, medium close-up, from the chest up, 50mm lens
```

`1girl` 和 `cowboy shot` 對寫實底模來說**不是指令,是雜訊**——
它沒學過這兩個詞。反過來寫實的句子丟給動漫底模效果也差。

**好消息是這件事 app 幫你處理了**:短劇分頁會照你選的底模自動換詞彙,
「風格靈感庫」也分成動漫 22 組、攝影 7 組兩條線,不會拿錯。
但你自己手打提詞的時候要知道這回事。

### 還有兩個底模自己的規矩

- **Pony 系**（Pony Diffusion、CyberRealistic Pony）的提詞**開頭一定要有**
  `score_9, score_8_up, score_7_up`,否則畫面會爛。app 幫你自動加。
- **NoobAI 和 Illustrious** 要把「CLIP skip」設成 **-2**（app 也幫你設好了）。

## 五、LoRA 認底模，選錯不會動

**這是 LoRA 最重要的一件事:** 一個 LoRA 是拿某個底模訓出來的,
就只能配那個底模（或同架構的）。

```
SDXL 的 LoRA  →  只能配 SDXL 系底模（LUSTIFY、epiCRealism、Juggernaut…）
Pony 的 LoRA  →  只能配 Pony 系底模（Pony、CyberRealistic Pony）
Illustrious 的 →  配 Illustrious / NoobAI
Wan 影片的    →  配 Wan 影片模型,不能配圖片底模
```

配錯的結果通常不是報錯,是**畫面爛掉或完全沒效果**。

app 在 LoRA 分頁會依你目前選的底模自動篩,所以照著它給的清單挑就不會錯。
但你自己從外面抓的時候,要看清楚那個 LoRA 頁面寫的 **base model** 是什麼。

## 六、自己抓 LoRA 進來（四條路）

到 **LoRA 分頁**,四條路都在同一頁:

### ① 用內建搜尋（最簡單）

打關鍵字或留空看熱門,按「裝」。它會自動只顯示跟你底模相容的。

### ② 貼網址（你自己在 CivitAI 找到的）

在 CivitAI 網站上找到想要的,**把網址列整條複製**貼進「貼 CivitAI 網址」,
按「找這個」。

```
https://civitai.com/models/573152                        ← 可以
https://civitai.com/models/573152?modelVersionId=3045803  ← 也可以，而且會選你正在看的那個版本
https://civitai.com/api/download/models/3045803           ← 也可以
```

它會告訴你這是 LoRA 還是底模、有哪些版本、觸發詞是什麼,再讓你選一個下載。

### ③ 匯入已經下載好的檔案

已經自己下載過的話,把那個 `.safetensors` 的**完整路徑**貼進去。
給一個**資料夾**的話,裡面所有 `.safetensors` 會一起匯入。
檔案是**複製**過去的,你原本那份不會被動。

### ④ 貼 HuggingFace 網址

HuggingFace 上也有很多人放訓練好的 LoRA。這裡**只認網址,沒有搜尋** ——
不是偷懶,是 HF 的分類資料不夠可靠:

- 它的 `filter=lora` **大半是語言模型的 LoRA**(實測前 8 名有 6 個是 Qwen/Gemma 的
  coder 模型),拿來當搜尋會一直給你 ComfyUI 根本載不進去的東西。
- 它**沒有 CivitAI 那種結構化的 base model 欄位**。有的話是作者自己填的 repo 名稱,
  而且搜尋結果裡是空的。**LoRA 配錯底模不會報錯,只是沒有效果** ——
  與其給你一個看起來很準其實在猜的相容性標示,不如老實說「作者沒標」。

所以貼進來之後它會:列出 repo 裡**所有**權重檔(一個 repo 常常不只一個 LoRA)、
標明作者有沒有說這是給哪個底模用的、然後讓你自己勾要哪些。

**只收 `.safetensors` 和 `.gguf`。** `.bin` / `.pt` / `.ckpt` 那類格式**載入時會執行程式碼**,
這裡一律不收,而且會告訴你它跳過了幾個。

> **下載 LoRA 和底模都要 CivitAI API key**（搜尋不用,下載要）。
> 到 <https://civitai.com/user/account> 產生一個,貼到「設定」分頁。
> **不要貼在別的地方,也不要傳給任何人。**

### 觸發詞是什麼

很多 LoRA 有「觸發詞」（trigger word）——一個特定的字,**提詞裡要打出來它才會作用**。
下載完 app 會把觸發詞存在旁邊,LoRA 清單裡看得到。

## 七、做寫實真人短劇的話，這三層各選什麼

| 層 | 選什麼 | 說明 |
|---|---|---|
| **圖片底模** | LUSTIFY! ZENITH v9 | 露骨鏡頭。穿著衣服的鏡頭用 epiCRealism XL |
| **畫風配方** | 「窗光人像」「汽車旅館夜戲」等 7 組攝影配方 | 不用下載 |
| **角色 LoRA** | **你要自己訓練** | 見下 |
| **影片模型** | Wan 2.2 I2V 14B | 讓關鍵幀動起來 |

### 為什麼角色 LoRA 要自己訓

動漫底模認得角色名字（打「hoshimachi suisei」真的會出現那個人）。
**寫實底模沒有這種東西**——它沒有「某個特定虛構人物」的概念。
所以要讓同一張臉出現在 25 顆鏡頭裡,只能自己訓一個 LoRA。

「訓練角色」分頁會一步步帶你做,詳細看 [`photoreal.md`](photoreal.md)。

整集短劇的流程看 [`short-drama.md`](short-drama.md)。

## 七之二、有些模型寫「這裡跑不了」怎麼辦

LTX、Wan S2V／Animate、MiniMax H3 這幾個下載完之後，在影片分頁的模型選單裡
是**灰的**,旁邊寫「這裡跑不了」。

不是壞掉。它們的官方流程是幾十個節點的圖,這個 app 沒有驗證過的版本可以跑
(而且沒有顯卡可以驗證)。**寫一個沒驗證過的圖當按鈕,比誠實說跑不了更糟。**

**但你可以把 ComfyUI 官方的那張圖拿過來用。** 到「模型」分頁最下面:

1. 在 ComfyUI(`:8188`)用 **Workflow → Browse Templates** 打開那個模型的官方範本,
   **先跑一次確認它會動**
2. 選 **Workflow → Export (API)** ← 注意是 **API** 那個,不是普通的 Export
3. 把存出來的 `.json` 丟到「模型」分頁的匯入框

app 會用白話告訴你它打算怎麼用:「你的圖片會放進 Starting image」、
「你打的提詞會進 Prompt」。**認錯了的話有「我自己選」可以改。**

存好之後,那個模型在選單裡就變成可以選的了,短劇分頁也能直接用它生成。

> **這不是我猜的圖 —— 是官方的圖,而且是在你自己的 ComfyUI 上證明跑得起來的那一份。**
> app 只負責填圖片、提詞、種子,以及把結果掛回鏡頭。

## 八、第一次用，照這個順序

1. **「模型」分頁** → 下載**一個**圖片底模（動漫選 NoobAI,寫實選 LUSTIFY）
2. **「設定」分頁** → 如果選了 CivitAI 的底模,貼上 CivitAI API key
3. **「圖片」分頁** → 打幾個字,按生成。先確認能跑起來
4. 想要特定角色 → **「LoRA」分頁**找一個裝上,或**「訓練角色」分頁**自己訓
5. 想做影片 → **「模型」分頁**再下載一個影片模型
6. 想做整集短劇 → **「短劇」分頁**

**卡在哪一步就停在那一步問**,不用照著全部做完。

## 名詞對照（看到不懂的字回來查）

| 看到 | 意思 |
|---|---|
| **底模 / checkpoint / 大模型** | 會畫畫的模型本體,6～7GB,一次用一個 |
| **LoRA** | 疊在底模上的小檔案,教它一件特定的事 |
| **觸發詞 / trigger word** | 要打進提詞裡,那個 LoRA 才會作用的字 |
| **base model** | 一個 LoRA 是給哪個底模用的。**配錯不會動** |
| **提詞 / prompt** | 你打的那段描述 |
| **負面提詞 / negative** | 你**不要**出現的東西 |
| **步數 / steps** | 畫幾次。20～30 就夠,再高多半只是變慢 |
| **CFG** | 多聽話。太低會亂畫,太高會僵硬。7 上下 |
| **seed / 種子** | 隨機種子。同樣的種子＋同樣的設定＝同樣的圖 |
| **sampler / scheduler** | 畫的演算法。不知道就用預設 |
| **CLIP skip** | 讀提詞讀多深。動漫底模要 -2,寫實要 -1。app 幫你設 |
| **fp8 / GGUF / Q4** | 同一個模型的壓縮版本,比較小、比較省顯存、品質略降 |
| **I2V / T2V** | 圖生影片 / 文生影片 |
| **關鍵幀** | 影片的第一張圖。影片是從這張圖長出來的 |
| **補幀** | 影片生成後把 fps 補高,看起來比較順 |
| **VRAM / 顯存** | 顯卡的記憶體。不夠會很慢,但通常還是跑得動 |
