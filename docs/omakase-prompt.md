# 給網頁版 Claude 的 prompt：抓 OMAKASE 的訂位開放規則

這個雲端環境被 Cloudflare 擋在 `omakase.in` 外面，所以那四家的開放規則得從別的地方拿。
把下面整段貼給有瀏覽能力的 Claude（claude.ai 網頁版，或 Claude for Chrome）。

規則文字通常公開就看得到；**空席日曆**才需要登入。所以網頁版能解決規則，不能解決空席。

---

```text
請幫我查四家東京餐廳在 OMAKASE 上的「訂位開放規則」。

網址：
1. 蒼（西麻布・イノベーティブ）https://omakase.in/ja/r/iz931441
2. とり茶太郎（渋谷・焼き鳥）https://omakase.in/r/hn429275
3. 明寂（西麻布・日本料理）https://omakase.in/r/ff108237
4. 酉囃子（麻布十番・焼き鳥）https://omakase.in/r/cn838977

我要的是「什麼時候可以開始訂位」的規則，例如：
- 毎月1日 10:00 に翌月分の予約を受付
- 3ヶ月前の同日より
- 30日前より
- 毎月最初の営業日に2ヶ月先の予約を承ります
- 【2026年10月分】2026年8月12日（水）17:00～19:00  ← 明確公告下次開放時刻

【非常重要】取消政策不是訂位規則。
像「3日前から50%、前日から100%のキャンセル料がかかります」這種是退費表，
它跟「3日前より予約受付」長得幾乎一樣，但意思完全相反。
只要那句話在講キャンセル／取消／変更手数料／ペナルティ，就不要當成規則。

【非常重要】查不到就說查不到。
不要從店家等級、類型或常見慣例去推測規則。猜錯會害我在錯的日子去搶訂，
比「不知道」更糟。頁面沒寫就照實回報 null。

每一家請用這個 JSON 格式回答，並把日文原文逐字照抄（不要翻譯、不要改寫）：

{
  "shop": "店名",
  "url": "網址",
  "ruleTextJa": "講開放規則的日文原文逐字照抄，沒有就 null",
  "announcementJa": "明確公告下次開放日期時刻的原文，沒有就 null",
  "whereOnPage": "這段文字出現在頁面哪個區塊（例如「予約について」欄、店舗情報、公告橫幅）",
  "requiresLogin": true 或 false（這段內容是否要登入才看得到）,
  "pageReachable": true 或 false（頁面是否打得開；被擋就 false）,
  "notes": "其他值得注意的（例如只接受電話、暫停接受新客、有訂位手續費）"
}

最後請附上你實際打開過的網址清單。
如果某個網址打不開（403、需要登入、Cloudflare 阻擋），直接說明是哪一種，
不要用搜尋結果或記憶去填補內容。
```

---

## 拿到回覆之後

把四段 JSON 原封不動貼回這個專案的對話就行。`ruleTextJa` 會直接餵進
`scraper/lib/tabelog.mjs` 的 `inferRule()`（它認得 毎月◯日 / ◯ヶ月前 / ◯日前 /
◯週間前 / 毎月最初の営業日），`announcementJa` 餵進 `parseAnnouncement()`。

規則進來之後，訂位雷達對這四家就會從「規則未確認」變成真正的倒數。
