RA 批次上傳工具

把 AUTOZONE MX 週報整理成 RA Client Container Status 的批次上傳格式

1選擇檔案
把 Excel 拖到這裡,或點一下選檔
支援 .xlsx / .xlsm — 檔案不會離開這台電腦
2日期檢查
3選擇要上傳的 milestone
4選項
5預覽
日期已修正 MBL 已加前綴 有疑慮,建議先確認
6匯出
匯出的檔案已符合 RA 格式:6 欄、沒有標題列、沒有空白列。 欄位順序為 Container # / MBL / Event / Date / Time / Update By。 日期與時間以文字寫入,避免再被任何地區設定重新解讀。
上傳步驟:RA → Client Container Status → Upload Excel → Excel 格式選 MBL# → 選檔 → Upload → 確認無誤後 Save。
